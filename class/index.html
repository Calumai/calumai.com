THE 12 MISSIONS

每一堂，都有一個可驗收成果。

01
GEMINI NOTEBOOK / GAME DESIGN

Gemini Notebook 遊戲化 RPG 簡報

把教材轉成世界觀、角色、任務與關卡，完成 8–12 張 RPG 簡報。

學會
遊戲化規則、來源控管、任務設計
實作
用太魯閣語上課用語 PDF 做案例
交付
RPG 簡報 v1、來源與提問紀錄
查看第 1 堂 PPT、講義與提示詞
02
VIBE CODING / QUIZ WEB

Vibe 你的學生測驗網頁

用同一條主線完成可作答、可回饋、可測試的單一 HTML 測驗；卡住拿救援卡，做完開支線。

學會
題庫資料、互動流程、回饋與除錯
實作
至少 5 題的學生測驗與 Bug 狩獵
交付
可開啟 HTML、提示詞與測試紀錄
查看第 2 堂 PPT、講義與提示詞
03
GEMINI + GAS / GOOGLE SHEETS

Gemini＋GAS 測驗成績系統

把學生姓名、班級、分數與作答內容送進 Google 試算表，部署成真正能分享的測驗網址。

學會
google.script.run、資料寫入、部署與權限
實作
Web App 串接 Google 試算表
交付
正式網址、測驗紀錄與真人測試
查看第 3 堂 PPT、講義與提示詞
04
GEMINI + GAS / AUTOMATION

Gemini + GAS 自動化題庫

讓題庫自動產生、整理、評分與留下紀錄，加入批次與錯誤處理。

學會
Apps Script、提示詞模板、結構化輸出
實作
Google Sheet 串接 Gemini
交付
題庫自動化工具與測試報告
查看第 4 堂 PPT、講義與提示詞

GOOGLE SITES / NETLIFY

讓你的網頁活起來：Google 協作平台與 Netlify 上架

學會
內容結構、嵌入與發布檢查
實作
Google Sites 或 Netlify 上架
交付

GAME GENERATION / FIVE FORMS

一份教材生出 5 種遊戲：生成方法
