THE WORKFLOW

三種角色，各做擅長的事

不是把同一個問題丟給三個工具，而是讓每一步都有明確責任。

01

NotebookLM

查、拆、對

  • 盤點來源與授權紀錄
  • 拆出事件、人物與因果
  • 找衝突、缺口並附引用

產出：故事事實包

→
02

聊天機器人

想、寫、規劃

  • 提出故事節拍與分頁方案
  • 把白話整理成 YAML
  • 組成單頁無字生圖工單

產出：可執行規格

→
03

作者與審訂者

審、改、定

  • 決定故事與創作空間
  • 確認語言、文化與權利
  • 判斷作品能否公開

產出：具名決定

YAML CARD SYSTEM

把故事拆成七張可以檢查的卡

YAML 不是為了炫技，而是讓 AI、作者與審訂者看到同一份規格。

  1. 00來源包能證明什麼
  2. 01故事內容事件與分頁
  3. 02視覺系統角色、場景、畫風
  4. 03權利／文化紅線不可改與待確認
  5. 04單頁工單一次生成一頁
  6. 05驗收規則PASS／FAIL
  7. 06製作紀錄版本與修正

HUMAN GATES

AI 可以初審，不能替人簽名

每一道關卡都要留下確認者、日期與待處理項目；沒有具名核准，就只能標示為課堂草稿。

Gate 1 · 19:50

來源可以用嗎？

確認可上傳範圍、個資、授權紀錄與文化紅線。

Gate 2 · 20:25

故事可以往下做嗎？

由作者核准節拍、不可改寫內容與允許創作的空間。

Gate 3 · 21:55

只能課堂看，還是能公開？

記錄驗收結果、語言文化審訂與正式公開狀態。

尚未完成任何真人關卡。
