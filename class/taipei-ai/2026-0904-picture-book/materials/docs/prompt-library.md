# A. NotebookLM：查、拆、對

## N-CLASS｜課堂快速故事資料表（當堂核心只用這一組）

```text
你是繪本來源管理員。只使用我目前勾選的來源，建立一份可交給作者確認的「故事資料表」。

請輸出五區：
1. 來源表：來源 ID、名稱、類型、可佐證什麼、文件中記錄的授權／審訂狀態、引用。
2. 事件表：順序、人物、動作、原因、結果、引用。
3. 不可改寫：鎖定名稱、原文、譯文、關鍵因果與適用範圍，逐項附引用。
4. 待確認：來源衝突、資料缺口、文化／語言／權利問題，以及需要誰確認。
5. 創作空間：來源沒有規定、但必須由作者決定的欄位。

規則：
- 來源沒有寫到就填「來源未記錄」，不得用常識補完。
- 遇到衝突時，不替我判定哪一項正確；授權、族語、服飾、祭儀、歷史或身分也交由適合的人確認。
- 不把一張人物或服飾照片當成整個群體、年代、性別或場合的通則。
- 每個重要主張都要有引用；找不到引用就不能放進「已確認」。
- 最後輸出「第一關來源檢查」清單：可繼續／需去識別／需真人確認／不得上傳或公開。
```

課堂中先用這一組完成故事資料表 `source-pack.md`，由老師或作者完成第一關來源檢查，再把確認過的內容交給聊天機器人 C01。以下 N01～N08 是拆開練習或課後進階，不需要在 20 分鐘內全部操作。

## N00｜筆記本共用規則

建議在本次繪本筆記本的第一輪先貼：

```text
你是本繪本專案的來源研究助手。

工作規則：
1. 只根據我目前勾選的來源回答。
2. 每個重要事實、引文、文化或語言說明都要附來源引用。
3. 來源沒有寫到，就標示「待確認」或「來源未記錄」，不得用常識補完。
4. 來源互相衝突時，並列各自說法與引用，不替我判定哪一項正確。
5. 明確分開「來源有佐證」、「AI 整理」與「可供作者創作的空白」。
6. 不判定授權、族語、服飾、祭儀或歷史一定正確；把這些項目交由真人確認。
7. 不把一張人物或服飾照片當成整個族群、性別、年代或場合的標準。

如果理解，先只回覆你將遵守以上規則，不要開始改寫故事。
```

## N01｜來源盤點表

```text
你是繪本來源管理員。只使用目前勾選的來源，建立表格：

來源 ID｜來源名稱｜來源類型｜可佐證的故事事實｜可佐證的文化／視覺細節｜文件中記錄的授權或審訂狀態｜不可據此推論的內容｜引用

要求：
- 文件沒寫授權狀態就填「未記錄」，不可自行判定可用。
- 若來源互相矛盾，另列「衝突清單」，不要自行判定哪一項正確。
- 來源沒有寫到的內容一律標示「待確認」。
- 最後列出開始改編前仍缺少的資料，並按「會阻擋製作／可稍後補」分類。
```

## N02｜原作事件核對

```text
只根據〔故事原文來源名稱〕整理原作事件核對表：

順序｜人物｜做了什麼｜原因｜造成的結果｜不可改動的關鍵台詞或詞語｜來源引用

規則：
- 不得補橋段、改因果或替缺漏合理化。
- 找不到證據時寫「原文未交代」。
- 將「原文事實」和「可能的改編空間」分成兩區。
- 最後指出哪些事件若刪掉，會改變故事核心。
```

## N03｜文化、語言與授權注意事項

```text
只依目前勾選來源，找出本繪本中需要特別保護的內容。

請分成：
1. 必須逐字保留的名稱、族語、譯文或關鍵句。
2. 有明確來源佐證的服飾、器物、地點、禮俗或歷史細節。
3. 來源只記錄特定人物、社群、年代、性別或場合，不能套用到其他人的內容。
4. 來源未說明、不可由 AI 猜測的內容。
5. 文件中記錄的使用、上傳、展示或公開限制。
6. 必須由作者、語言老師、文化知識持有人或權利人確認的項目。

每項輸出：內容｜適用範圍｜來源引用｜目前狀態（已確認／待確認／禁止推論）｜建議確認者。
如果文件沒有授權說明，只能寫「授權未記錄」。
```

## N04｜故事段落拆解（課後拆開練習）

```text
根據已核對的原作事件，把故事分成下列可能的段落：設定、觸發、升級、停頓、反應、轉折、高潮、收尾。

每個段落輸出：
- beat_id
- 這段在故事中的作用
- 主要人物與動作
- 前一段如何造成這一段
- 情緒強度（低／中／高）
- 對白密度（無／少／中／多）
- 必須看見的畫面資訊
- 來源有佐證或待作者決定
- 來源引用
- 是否需要語言／文化真人確認

先整理故事段落，再依各段重要程度安排成這次練習室使用的 4～6 頁。
說明哪些段落需要合併或拆開；內容不足或過多時，列出需要補問或精簡之處，不得硬塞，也不得改動「不能更動的內容」清單。
```

## N05｜角色與場景事實表

```text
只使用目前勾選的來源，建立「角色與場景事實表」。這不是自由想像，也不是生圖提示詞。

角色欄位：
角色 ID｜姓名或稱呼｜關係與角色功能｜來源明確寫出的外觀｜來源明確寫出的服裝／配件｜性格與行動證據｜不可變項｜未知項目｜引用

場景欄位：
場景 ID｜地點｜時間｜來源明確寫出的空間與固定物件｜光線／季節證據｜不可新增元素｜未知項目｜引用

要求：
- 圖片來源要說明「畫面看得到什麼」，不要推測看不到的角度。
- 來源沒寫的膚色、服飾名稱、圖紋意義、材料或身分，全部標示「待確認」。
- 最後列出可交給作者自由設計、但需明確標成創作決定的欄位。
```

## N06｜分齡文字核對與改寫建議（課後進階）

```text
請將已核對的故事文字調整成適合〔年齡／閱讀程度〕的版本。

逐段輸出：
原文｜精簡／改寫建議｜改寫理由｜必須保留不動的詞語｜是否改變原意｜來源引用｜需作者確認事項

限制：
- 可以縮短句子與降低難字，但不得改變人物、動作、因果、文化意義及鎖定詞語。
- 可能改變原意的句子只能列為建議，標示「需作者確認」。
- 不新增道德結論或原文沒有的文化解釋。
```

## N08｜把草稿重新上傳後做初步來源核對（課後進階）

先把目前 PDF／PPTX 上傳成來源並命名為 `DRAFT-v01`，再貼：

```text
你是來源核對助手。請比較 DRAFT-v01、故事原文、角色／場景事實表、文化審訂資料及驗收規格。

逐項輸出：
檢查項目｜PASS／FAIL／待真人確認｜草稿證據｜原始來源引用｜只改必要部分的指令

至少檢查：
- 人物、事件順序與因果
- 鎖定名稱、原文與譯文
- 角色與場景固定特徵
- 是否新增來源沒有佐證的文化或歷史主張
- 哪些是合理的創作決定、是否已標示
- 授權或真人審訂狀態是否被誤寫成已完成

任一來源忠實、文化、語言或授權硬條件失敗，整體不得通過初步核對。
不要替草稿找理由，也不要重寫整本；只指出需要修改的部分。
```

這只是同一工具內的初步來源比對，不算獨立的最後驗收。正式驗收仍要由沒有參與生成的同儕或另一個新對話執行，並由真人決定文化、語言、權利與公開狀態。

# A2. 教師教材：先選成品，再貼一組

T01～T06 貼到 `工作室 → 簡報 → 鉛筆`；T07～T10 貼到 `工作室 → 資訊圖表 → 鉛筆`。T11～T20 是其他文字備課與工作室工具，需要時再用，不必全部操作。

## T01｜一堂課上台教學簡報

用途：把教案、課文與講義做成老師上台講解用的投影片。操作位置：`工作室 → 簡報 → 鉛筆`，格式建議選「簡報投影片」。

```text
請只根據目前勾選的來源，為〔年級／科目〕製作一份老師上台講授〔主題〕的繁體中文簡報。

請規劃 8～10 張投影片：
1. 課名、對象與今天要學會的事。
2. 一個能連結先備經驗的開場問題。
3.～6. 每頁只講一個核心概念，搭配來源有佐證的例子或圖像建議。
7. 一個完整示範或證據解讀。
8. 一題讓學生當場回答的理解檢核。
9. 三點重點整理。
10. 一題離堂任務；若總頁數較少，可和重點整理合併。

版面使用大字、少字、高對比，適合教室投影。每頁最多三個短要點，不把教師口頭說明全部塞進畫面。來源未提供的資料標示「教師確認」，不得自行補造數字、文化意義、傳統圖紋、服飾或專有名詞。生成後請老師逐頁對照原始來源。
```

## T02｜學生可獨立閱讀的複習簡報

用途：做成缺課補課、課後複習或學生自學用的完整版本。操作位置：`工作室 → 簡報 → 鉛筆`，格式建議選「詳細簡報」。

```text
請只根據目前勾選的〔課文／講義／詞彙表〕，為〔年級／科目〕製作一份學生不聽老師講解也能讀懂的繁體中文複習簡報。

內容依序包含：
- 本單元要回答的核心問題。
- 先備知識與關鍵詞。
- 4～6 個核心概念；每頁提供白話說明、來源中的例子及「為什麼重要」。
- 一頁常見混淆與辨認方法。
- 三題自我檢核，最後另列答案與來源依據。
- 一頁總結與下一步複習建議。

一頁只負責一件事，文字可以比上台簡報完整，但仍保持短段落與清楚層級。不得新增來源沒有的例子當成事實；重要名稱與詞語沿用來源原文。生成後由老師核對答案、數字與引用再提供給學生。
```

## T03｜分齡視覺比喻簡報

用途：把抽象或複雜概念換成適合指定年齡理解的視覺說法。操作位置：`工作室 → 簡報 → 鉛筆`。

```text
請只根據目前勾選的來源，把〔抽象概念〕製作成給〔年級／年齡〕學生看的 6～8 張繁體中文視覺比喻簡報。

每張投影片包含：
1. 一個簡短標題。
2. 一個貼近學生生活、但不扭曲來源的視覺比喻。
3. 兩句白話說明。
4. 一句「這個比喻不能代表什麼」，避免學生過度延伸。

最後一頁用來源中的真實例子把比喻拉回正式概念。避免堆太多專有名詞；若必須使用，先保留正確原文，再加白話解釋。文化、歷史或族語內容不得用來源沒有佐證的比喻取代，也不得自行創作傳統圖紋或服飾。
```

## T04｜常見迷思與問答簡報

用途：考前複習、課堂澄清或操作教學，一頁處理一個學生常問的問題。操作位置：`工作室 → 簡報 → 鉛筆`。

```text
請以目前勾選的教材，以及已去除姓名與可識別資訊的匿名常見錯誤，製作〔主題〕的繁體中文「迷思與問答」簡報。

先找出最多 8 個來源確實能回答的重要問題。每張投影片依序放：
- 學生可能會問的問題。
- 一句直接答案。
- 2～3 個判斷步驟或解釋。
- 一個來源中的例子或證據。
- 一句「最容易搞混的是什麼」。

最後一頁整理三個自我檢查問題。若匿名錯誤資料不足以證明某項迷思很常見，請寫「教師觀察待確認」，不要冒充統計結論。不得呈現任何學生姓名、座號、原始作答或可識別內容。
```

## T05｜歷史與文化時間軸簡報

用途：把事件的先後、原因與影響做成可講解的時間軸。操作位置：`工作室 → 簡報 → 鉛筆`。

```text
請只根據目前勾選且已審定的史料／年表，製作〔主題〕的繁體中文時間軸簡報，共〔6～10〕張。

每張投影片只處理一個時期或事件，包含：
- 日期或時期；來源沒有精確日期時照原文標示。
- 事件名稱。
- 事件發生前的背景。
- 來源有佐證的原因。
- 來源有佐證的影響。
- 與上一事件的關係。

開頭先給全覽時間軸，結尾整理「改變了什麼／沒有足夠資料判斷什麼」。不同來源說法不一致時並列呈現並標示待確認，不替我判定哪一項正確。不得自行補造歷史細節、文化意義、傳統圖紋、服飾或族群通則。
```

## T06｜概念比較與對照簡報

用途：協助學生辨認兩個以上概念、文本或觀點的共同點與差異。操作位置：`工作室 → 簡報 → 鉛筆`。

```text
請只根據目前勾選的來源，為〔年級／科目〕製作〔概念 A〕、〔概念 B〕〔必要時加入概念 C〕的繁體中文比較簡報。

投影片依序包含：
1. 比較目的與共同問題。
2. 各概念在來源中的定義。
3. 共同點。
4. 關鍵差異，使用同一組比較面向。
5. 各自在來源中的例子。
6. 一個容易混淆的反例或邊界。
7. 一題要求學生說明判斷依據的練習。
8. 答案範圍與來源核對提醒。

版面以左右對照或矩陣呈現，兩邊資訊量保持平衡。來源沒有提供的比較面向標示「資料不足」，不得用常識補成結論。
```

## T07｜一頁課前預習資訊圖表

用途：上課前讓學生先看懂主題與關鍵詞。操作位置：`工作室 → 資訊圖表 → 鉛筆`，建議選「直向」與「精簡」。

```text
請只根據目前勾選的課文與學習目標，製作一張給〔年級／科目〕學生課前預習的繁體中文資訊圖表。

畫面依閱讀順序包含：
- 一句主題標題。
- 3～5 個本課最重要的觀念，每個觀念不超過兩行。
- 最多 8 個關鍵詞及一句白話說明。
- 一個「上課前先想想」的帶入問題。
- 一個提醒學生上課時要找的證據。

使用大字、少字、清楚層級與教室投影可讀的高對比配色。不要塞滿整頁。只使用來源有佐證的內容；專有名詞保留正確拼寫，來源未記錄的圖像、文化意義、傳統圖紋或服飾不要補畫。
```

## T08｜步驟與安全提醒資訊圖表

用途：把實驗、手作、數位操作或課堂活動流程變成學生能跟著做的圖。操作位置：`工作室 → 資訊圖表 → 鉛筆`，依流程方向選直向或橫向。

```text
請只根據目前勾選的正式操作說明與安全規則，製作〔活動名稱〕的繁體中文步驟資訊圖表。

請分成：
1. 開始前要準備什麼。
2. 依順序編號的 5～8 個操作步驟；每一步只放一個動作。
3. 必須特別注意的安全警示。
4. 完成後的檢查與收拾方式。
5. 遇到設備失效時的備援方式；來源沒有就標示「請詢問老師」。

用清楚箭頭呈現方向，警示和一般步驟要能一眼區分。不得自行增加化學、醫療、電器或戶外安全規則；所有安全內容需由老師回到正式規範核對。
```

## T09｜概念關係資訊圖表

用途：把分類、因果、部分與整體或概念之間的關係畫清楚。操作位置：`工作室 → 資訊圖表 → 鉛筆`，建議選「橫向」與「標準」。

```text
請只根據目前勾選的教材與詞彙表，製作〔主題〕的繁體中文概念關係資訊圖表。

請先辨認這批來源最適合的關係類型：分類、順序、因果、部分與整體，或比較；只選一種主結構，不要混成複雜蜘蛛網。

畫面包含：
- 位於中心或起點的核心概念。
- 4～7 個次概念。
- 每一條線或箭頭旁寫明關係，例如「包含」「造成」「發生在……之後」。
- 2～3 個來源中的例子。
- 一個學生可以用圖回答的檢核問題。

來源沒有明說的關係不得自行連線；不確定處標示「待老師確認」。少字、大字、高對比，投影時仍可讀。
```

## T10｜去識別化資料重點資訊圖表

用途：把調查、學習結果或報告中的關鍵數字變成一頁重點圖。操作位置：`工作室 → 資訊圖表 → 鉛筆`，建議選「專業」視覺風格。

```text
請只根據目前勾選、已去除姓名與可識別資訊的 Sheets／CSV／報告，製作〔主題〕的繁體中文資料資訊圖表。

只挑 3～5 個最能回答〔教學問題〕的關鍵數字，逐項呈現：
- 指標名稱與數值。
- 分母、樣本數、期間或範圍。
- 可以從資料直接看出的趨勢。
- 不能由這份資料推論的事情。
- 老師可帶學生討論的一個問題。

數值、單位、百分比與圖例必須清楚；不得把相關性寫成因果，也不得顯示姓名、座號、學號、原始作答或小樣本可識別資訊。若資料定義不清，停止下結論並標示需老師核對。
```

## T11｜40 分鐘教師備課卡

適合把課綱、教科書章節、教師手冊與自己的教學筆記整理成可修改的第一版教案。

```text
你是教師備課研究助手。只使用我目前勾選的來源，為〔年級／科目〕整理一堂〔分鐘〕分鐘的教師備課卡。

請輸出：
1. 本課核心概念與來源引用。
2. 2～3 個可觀察的學習目標；若來源沒有課綱依據，標示「教師決定」，不要冒充正式指標。
3. 學生需要的先備知識，以及來源有佐證的常見困難。
4. 分鐘流程：引起動機、教師示範、學生練習、全班整理、離堂檢核。
5. 每一段需要的教材、教師提問與學生可觀察行為。
6. 一個不依賴額外設備的備援活動。
7. 課前仍需教師確認的事實、語言、文化、授權或班級差異。

規則：
- 每個關鍵概念與正確答案都要附引用。
- 來源沒有寫到的教法只能標「教學建議」，不得寫成來源事實。
- 不使用學生姓名、個別診斷或未去識別的資料。
```

## T12｜同材異質三層閱讀支援

```text
只根據目前勾選的同一組教材，為〔年級／主題〕設計三種閱讀支援路徑：需要較多鷹架、標準閱讀、延伸挑戰。

請用對照表輸出：
核心概念｜必須保留的原詞或事實｜鷹架版說明與任務｜標準版說明與任務｜延伸版說明與任務｜來源引用｜教師確認事項

要求：
- 三組都學同一個核心概念，不把任何學生貼上能力標籤。
- 鷹架版可以縮短句子、加步驟、加詞彙提示，但不得刪掉核心因果或改掉鎖定詞。
- 延伸版增加比較、證據或應用，不新增來源外的知識當成正解。
- 最後各給一題離堂檢核，並說明教師要觀察什麼。
- 不根據姓名、族群、身心狀況或個人背景推測學生能力。
```

## T13｜學習單與教師答案版

```text
只使用目前勾選的教材，為〔年級／主題〕製作一份可在〔分鐘〕分鐘完成的學習單草稿，以及分開的教師答案版。

題目配置：
- 3 題找得到原文證據的理解題。
- 3 題需要比較、排序或說明因果的題目。
- 2 題需要引用來源證據作答的短答題。
- 2 題可連結學生經驗、但不把個人經驗當成來源事實的延伸題。

每題附：題型｜題目｜作答要求｜答案或評分重點｜來源引用｜常見錯誤提醒。

規則：
- 來源不足以判定唯一答案時，改成開放題並寫清楚評分依據。
- 不設計靠猜測文化、身分、語言或未提供背景才能答對的題目。
- 教師答案版要和學生題目分開，且所有正確答案可回到來源核對。
```

## T14｜匿名評量結果與補救教學

先上傳去除姓名、座號、學號與可識別資訊的題目、答案規準及全班彙整結果，再使用：

```text
你是教師的評量診斷助手。只使用目前勾選的題目、答案規準、教材來源與匿名彙整結果。

請輸出：
題號／概念｜匿名結果顯示的現象｜可能的迷思（有證據才寫）｜來源或資料證據｜不能從資料判斷的事｜10 分鐘補救活動｜一題離堂檢核

接著提出：
1. 全班先教的共同問題。
2. 可用任務需求分組的練習方式；不得替學生貼固定能力標籤。
3. 需要教師查看原始作答才能判斷的項目。
4. 這份資料無法佐證的結論。

不得輸出或推測任何學生姓名、身分、診斷、家庭背景或族群特徵。
```

## T15｜臨時代課教師交接單

```text
只根據目前勾選的課表、教案、班級規則與教材，製作一頁式「代課教師交接單」。

請依序整理：
- 班級、節次、教室與本堂目標。
- 這堂課開始前要準備的教材與設備。
- 逐段時間、教師要說明的重點、學生任務與收回物。
- 不可改動的詞語、文化／語言說明與安全規則。
- 設備失敗或進度落後時的備援方案。
- 下課前要留下的紀錄，以及原任教師需要接手的未完成事項。
- 每個重要教學內容的來源引用。

規則：
- 來源沒寫到的班級慣例填「未記錄」，不可自行補。
- 不放學生姓名、座號、醫療、家庭、行為或其他個人資料。
- 最後列出「原任教師仍需補充」清單。
```

## T16｜核心詞彙與鎖定用語表

```text
只使用目前勾選的來源，為〔年級／主題〕整理最多 15 個核心詞彙。

請輸出表格：
詞彙｜來源中的原文或正確拼寫｜來源有佐證的意思｜給學生的白話說明｜來源中的例句或情境｜容易混淆的詞｜不可任意改寫事項｜引用

要求：
- 族語、專有名詞、人名、地名與文化詞保留原文，不自行改拼寫、斷詞、翻譯或造例句。
- 來源沒有發音、詞性、例句或譯文時填「來源未記錄」。
- 白話說明不得加入來源沒有的文化意義。
- 最後提供 5 分鐘配對活動；答案必須能由表格核對。
```

## T17｜分層討論題與教師追問

```text
只根據目前勾選的教材，為〔年級／主題〕設計一組教師可帶領的討論題。

請分成三層：
A. 找證據：3 題，學生能直接指出來源段落或圖表。
B. 連關係：3 題，要求比較、排序、說明因果或觀點差異。
C. 做判斷：2 題，學生必須引用來源後才能提出自己的解釋。

每題輸出：主問題｜必要來源｜可能的合格答案範圍｜教師追問 2 題｜常見誤解｜不宜由 AI 代答的文化／價值判斷。

來源互相衝突時，將衝突設計成比較題，不替我判定哪一項正確。來源沒有答案時要明說，不得把常識當成指定答案。
```

## T18｜NotebookLM 教師備課 Audio Overview（語音摘要）

操作：在工作室選擇 `Audio Overview`（語音摘要），先選適合的格式（快速掌握可用 The Brief；深入備課可用 Deep Dive），再把下列文字貼到自訂提示欄。不同帳號可見的格式可能不同。

```text
這份音訊是給〔年級／科目〕教師的備課預聽，不是直接給學生播放的正式教材。

請聚焦：〔本課核心概念或教師最需要先理解的問題〕。
請依序說明：
1. 各份來源都有佐證的 3～5 個重點。
2. 來源之間的差異、衝突或資料缺口。
3. 學生最可能混淆的地方；只有來源有證據時才判定為常見迷思。
4. 教師進教室前必須再次核對的語言、文化、授權或數字。
5. 最後用三個備課檢查問題收尾。

使用繁體中文。不要用主持人口吻替來源下結論；找不到依據就明說「來源未記錄」。
```

## T19｜NotebookLM 工作室測驗／字卡自訂提示

操作：在工作室的 `Quizzes`（測驗）或 `Flashcards`（字卡）點選自訂／鉛筆圖示，選擇難度與數量，再貼入：

```text
對象是〔年級／科目〕，範圍只限目前勾選來源中的〔單元〕。

請優先檢查：〔核心概念 1〕、〔核心概念 2〕、〔鎖定詞語〕。
題目要能讓學生解釋「為什麼」，不要只測零碎記憶；每個答案或解釋都必須能回到來源核對。
混合直接理解、比較因果與來源證據題，不出來源沒有唯一答案的陷阱題。
族語、文化、人名、地名及專有詞只使用來源中的正確形式；不自行造例句或推論文化意義。
若來源不足以佐證題目，請不要生成該題。
```

## T20｜分享筆記本前的來源安全檢查

NotebookLM 的分享畫面可能仍讓觀看者接觸來源或工作室產生的內容；「Chat View」（聊天檢視）也不等於撤銷來源存取。分享前先使用：

```text
你是教師的分享前檢查助手。只根據目前勾選來源中已記錄的內容，建立分享風險盤點；不要真的變更分享設定。

逐一輸出：
來源名稱｜預計教學用途｜可能包含的姓名／學生作品／肖像／聯絡資料／未公開內容／文化敏感資訊｜文件中記錄的授權範圍｜可否讓全班查看（可／待確認／不可）｜分享前教師動作｜引用

再檢查已生成的常見問答、學習單、音訊、簡報或其他工作室內容是否可能暴露上述資料。

規則：
- 來源未寫授權就填「授權未記錄」，不得判定可以公開。
- 不以去掉姓名就自動判定安全；仍要檢查內容是否可識別個人或社群。
- 最後分成：可在受限班級使用／需權利人或文化審訂者確認／不得分享。
- 最終分享決定由教師、學校與權利人作成，不由 AI 代替。
```

### 教師功能依據與帳號提醒

# B. 聊天機器人：想、寫、規劃

## C00｜先訪談，不急著生故事

```text
你是我的繪本製作訪談助手。先不要寫故事、不要生圖、不要產 YAML。

請一次問我最多 5 個最重要的問題，釐清：
- 讀者年齡與閱讀程度
- 故事核心與希望留下的感受
- 原始來源與我有權使用的範圍
- 哪些事實、語言或文化內容不能改
- 我今天要完成幾頁規劃、幾張完成圖

一次只問必要問題。我沒提供的資料不要替我假設。
等我回答後，先整理成「已知／待確認／不可推論」三區，讓我確認後才進下一步。
```

## C01｜把確認過的故事資料分段，再安排成 4～6 頁

```text
以下「故事資料表」（可以是確認過的 Markdown，或 `00-source-pack` YAML）是目前唯一可確認的內容。你可以提出創作選項，但不得把選項改寫成來源事實。

〔貼上 source-pack.md〕

任務：
1. 先用設定、觸發、升級、停頓、反應、轉折、高潮、收尾把故事分段。
2. 每個段落標示：這段的作用、人物動作、因果、情緒強度、對白多寡、來源有佐證／創作提案、需真人確認事項。
3. 將故事段落安排成這次練習室使用的 4～6 頁，說明哪些段落需要合併或拆開。
4. 若故事內容不足或過多，先列出要補問、精簡或重新安排的地方，不可硬塞；等作者核准後才寫每頁內容。

限制：
- 不得更改不可改寫清單。
- 未知內容保留「待確認」。
- 每頁只安排一個主要敘事動作。
- 先等我選定方案，不要直接寫完整內文。
```

## C02｜把白話轉成內容 YAML

```text
你是 YAML 編輯助手。請把我確認過的故事資料、故事段落與分頁方案填入我提供的 `01-content.template.yaml`。

規則：
- 保留原模板欄位與欄位順序。
- 只輸出一個可解析的 YAML 程式碼區塊，不加前言與結語。
- 字串含冒號、井字號或特殊符號時加引號。
- 不知道的值填 null；需真人確認的值填 status: pending_human_review。
- 每個來源事實填 source_refs；AI 提案填 decision_type: creative_proposal。
- 不改動 locked_text 與 non_negotiables。
- 不新增來源沒有的族語、服飾、歷史、祭儀或人物身分。

輸入資料：
〔貼上故事資料表、故事段落、方案與模板〕
```

## C03｜建立角色、場景與畫風 YAML

```text
根據已通過第一關來源檢查的 `N-CLASS` 故事資料表（課後也可改用 N05 詳細表），以及作者提出的視覺方向，填入 `02-visual-system.template.yaml`。

請分開處理：
1. character_anchors：臉型、髮型、身形比例、服裝、配件、五個不可變特徵。
2. scene_anchors：地點、固定物件、時間、光線、配色、不可新增元素。
3. style：線條、材質、配色、人物比例、背景、光影、構圖習慣、避免事項。
4. output：比例、尺寸、檔案格式與文字政策。

規則：
- 來源事實與作者創作決定要分開標示。
- 只看得到正面的參考圖，不得補背面結構。
- 不用「民族風」等模糊詞替代具體證據。
- 不模仿特定在世創作者；改用可觀察的線條、材質、配色與構圖描述。
- 未確認文化欄位填 null 或 pending_human_review。
- 只輸出一個可解析的 YAML 程式碼區塊。

資料：
〔貼上 N-CLASS 已確認內容、作者視覺提案與模板〕
```

## C04｜建立文化與語言限制 YAML

```text
把 `N-CLASS` 的「不可改寫、待確認、來源與權利」內容填入 `03-culture-guardrails.template.yaml`；課後也可改用 N03 的詳細結果。這是限制卡，不是美術裝飾卡。

要求：
- scope 要寫清楚適用的人、社群、地點、年代、性別與場合；未知填 null。
- confirmed_features 只能放有來源且已確認的內容。
- uncertain_features 必須附需要誰確認。
- prohibited_generalizations 要明確列出不得從單一人物或照片推論整個群體。
- language_locks 的 exact_text 不得潤飾、改拼寫或自動翻譯。
- 未完成真人確認時，overall_status 必須是 pending_human_review。
- 只輸出一個可解析的 YAML 程式碼區塊。

已核對資料與模板：
〔貼上 N-CLASS 已確認內容及模板〕
```

## C05｜建立單頁繪本／漫畫生圖設定

```text
請讀取我提供的內容卡、視覺卡、文化與語言限制卡，以及 `04-page-drawing-job.template.yaml`，只為第〔頁碼〕頁建立一份單頁生圖設定。

這一頁資料：
- story_beat：〔故事段落 ID〕
- 本頁唯一主要動作：〔動作〕
- 頁面形式：〔繪本單一主畫面／2 格漫畫／3 格漫畫／4 格漫畫〕。只有同一頁需要呈現連續動作時才選漫畫。
- 漫畫閱讀順序與各格動作：〔例如：由左到右；第 1 格角色抬頭、第 2 格角色跑向門口。非漫畫頁填不適用〕
- 本頁文字預計放在：〔左／右／上／下〕
- 必須看見：〔元素〕
- 不得出現：〔元素〕

規則：
- 引用既有 character_id 與 scene_id，不另創造角色或場景。
- 只描述本頁一個主要敘事動作。
- 若為漫畫頁，整頁只推進一個主要事件；依閱讀順序列出每一格的角色、單一動作與鏡位，不把不相干的場景塞在同一頁。
- 明確寫 shot_size、camera_angle、subject_position、negative_space。
- 複製文化與語言限制，不自行簡化。
- text_policy 設為 no_generated_text。
- 只輸出一個可解析的 YAML 程式碼區塊。

〔貼上四份 YAML〕
```

## C06｜把單頁設定組成無字繪本／漫畫頁提示詞

```text
你是生圖提示詞組裝員，不是故事作者。

請只根據以下已確認資料，組成一份可交給〔生圖工具名稱〕的繁體中文提示詞：
- 本頁 drawing job（單頁生圖設定）
- 被引用的角色 anchor（角色固定設定）
- 被引用的場景 anchor（場景固定設定）
- style
- culture guardrails（文化與語言限制）

輸出順序：
1. 畫面主體與唯一主要動作
2. 角色不可變特徵
3. 場景固定特徵
4. 鏡位、構圖與文字安全留白
5. 若為漫畫頁：先逐格列出角色、單一動作與鏡位，再寫分格數量、清楚邊界與閱讀順序；每格沿用同一份角色固定設定

- 不新增角色、配件、建築或象徵。
- 不使用特定在世創作者姓名描述風格。

只輸出「正向提示詞」和「負向提示詞」兩區，不解釋。

〔貼上已確認資料〕
```

## C07｜開新對話做獨立驗收

這組提示詞要放在另一個新對話，或交給沒有參與生成的同學。

```text
你是獨立驗收員，不是生成者。只依我提供的來源、YAML 單頁生圖設定、參考圖、成品和 criterion（驗收規則）判定；不要替作品找理由，也不要用你自己的常識補資料。

逐項輸出：
check_id｜檢查項目｜PASS／FAIL／待真人確認｜成品可見證據｜來源或單頁設定證據｜只改必要部分

規則：
- 找不到證據不能判 PASS。
- 角色、故事因果、鎖定文字、文化、語言或授權任一硬條件失敗，整頁不得通過。
- 只指出需要修改的部分，不重寫整本。
- 文化、語言與權利項目即使畫面看似合理，也可標「待真人確認」。

最後只輸出：
overall_status: PASS／FAIL／PENDING_HUMAN_REVIEW
failed_checks: [check_id]
next_action: 一句只改必要部分的指令，或人工確認行動

〔貼上來源、YAML、參考圖、成品與 criterion〕
```

## C08｜失敗頁一次只修一個問題

```text
第〔頁碼〕頁在第〔嘗試次數〕次驗收未通過。

原單頁生圖設定：
〔貼上 drawing job〕

失敗證據：
〔貼上 failed check 與可見證據〕

任務：
1. 保留所有已通過欄位不變。
2. 只修改造成失敗的最少欄位。
3. 產出更新後的 drawing job YAML（單頁生圖設定）。
4. 另外輸出一句「本次只修改了什麼」。
5. 若已是第 3 次失敗，不再重新生成，改輸出 `escalate_to_human: true` 與人工處理建議。

不得藉機更換角色、畫風、場景或重寫故事。
```

# C. 一次只換一個變因的練習

## 比較兩種畫風，不改故事

```text
保持 content、character_anchors、scene_anchors、page drawing job 與 culture guardrails 完全不變。

只建立兩張不同的 style YAML：
A. 柔和透明水彩：細鉛筆線、紙張水分邊緣、低飽和暖色、背景簡化。
B. 剪紙拼貼：明確紙張層次、平面色塊、少量纖維質感、清楚輪廓。

兩張卡使用完全相同欄位，讓我逐欄比較。不要使用特定在世創作者姓名，也不要改變角色或文化內容。
```

## 找出五個角色不可變特徵

```text
請根據我有權使用的角色參考圖與文字說明，先列出畫面可直接觀察的特徵，不推測身分、族別或看不到的細節。

再請我從中選 5 個跨頁不可變特徵。等我選完後，才寫入 character_anchor.do_not_change。

若特徵涉及服飾、器物或文化意義，標示「需真人確認」，不要自行命名或解釋。
```
