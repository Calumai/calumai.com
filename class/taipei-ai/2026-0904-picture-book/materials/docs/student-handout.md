# 學員操作講義｜三小時做出可繼續完成的 AI 繪本原型

## 今天要完成什麼

你不需要在三小時內硬做完一本精修繪本。今天的基本目標是：

- 4-6 頁故事規劃完整。
- 至少 1 張頁面完成無字生圖、排版與驗收；順利者繼續補齊 4-6 頁小繪本。
- 保留來源、提示詞、YAML、源稿和驗收紀錄。

線上練習室可以把同一組參考圖、角色設定與畫風鎖定套用到全部 4-6 頁；請先完成並檢查文字分鏡，再逐頁生成。課堂不要求一次把每張都精修到完美。

若畫面包含傳統服飾、圖紋、器物或文化場景，不能只把它當成一種畫風。請先填清楚族群／地域／來源範圍、允許呈現的細節與不可改動事項，並請有權判斷的人完成審訂；AI 不可以自行猜測、混搭或補畫參考圖沒出現的內容。

## Step 1｜先選故事，不要急著畫

寫下：

- 我的故事暫名：`____________________`
- 想給誰看：`____________________`
- 看完希望他感受到／學到：`____________________`
- 原始來源：`____________________`
- 我有權上傳與使用嗎：`是／待確認／否`
- 絕對不能被 AI 改寫的內容：`____________________`

如果有真人、兒童、族語、服飾、祭儀、歷史、地方知識或未公開資料，先標黃燈，請講師協助判斷。

## Step 2｜用 NotebookLM 建立故事事實包

1. 新建一個本次專用筆記本。
2. 加入故事原文、授權說明、核准的語言／文化說明，以及附圖說的參考圖。
3. 只選取本題需要的來源。
4. 當堂只使用提示詞庫中的 `N-CLASS｜課堂快速事實包`；N01–N08 留作拆開練習或課後進階。
5. 把結果存成 `source-pack.md`。

檢查：重要內容有引用嗎？找不到的資料有沒有誠實寫「待確認」？

## Step 3｜請聊天機器人先拆節拍

把核准的故事事實包貼給聊天機器人，使用 `C01 故事節拍與頁數`。

先看故事是否有：

- 設定：誰、在哪裡、平常狀態。
- 觸發：發生什麼事情，故事開始動。
- 發展：行動與阻礙怎麼增加。
- 停頓／反應：角色如何感受或選擇。
- 轉折／高潮：最大的改變或決定。
- 收尾：結果與讀者帶走的感受。

節拍完整後再配置成練習室 4-6 頁，說明哪些節拍要合併或拆開，不要硬塞故事。

## Step 4｜把決定存進 YAML 卡片

依序填：

1. 把已確認的事實包存成 `00-source-pack.template.yaml` 或保留核准的 Markdown 版。
2. 填 `01-content.template.yaml`。
3. 填 `02-visual-system.template.yaml`。
4. 每個專案都填 `03-culture-guardrails.template.yaml`；文化與語言可填不適用，但權利與個資不可略過。
5. 為今天要完成的頁面複製一份 `04-page-drawing-job.template.yaml`。
6. 驗收與記錄直接使用公版 `05-criterion.template.yaml`、`06-production-log.template.yaml`；課後再客製。

可以請聊天機器人幫忙轉格式，但每一欄都要由你確認。沒有答案就填 `null` 或 `待確認`，不要讓 AI 猜。

## Step 5｜做角色和場景基準

先決定角色「五個不能變」：

1. 臉型／明顯五官：`____________________`
2. 髮型：`____________________`
3. 身形比例：`____________________`
4. 服裝：`____________________`
5. 配件或識別物：`____________________`

再決定場景固定物件、時間、光線與色盤。若服飾或物件涉及文化知識，只抄錄已核准來源；看不到的角度不要補畫。

## Step 6｜逐頁產生無字圖

先完成一張關鍵內頁；順利者再做封面＋另一張關鍵內頁：

1. 每一頁複製一張單頁工單。
2. 固定角色、場景和畫風卡。
3. 只替換本頁節拍、動作、鏡位與留白。
4. 明確要求「圖內不出現文字、字母、數字、標誌或浮水印」。
5. 每次結果存檔，記下嘗試次數和問題。
6. 到 21:10 還沒有可用圖，就使用講師備援圖繼續排版；把失敗原因留下來，課後再重試。

不要在每一頁重新描述一個不同的主角。YAML 與參考圖會提高一致性，但不保證完全一致，所以要並排檢查。

## Step 7｜在排版工具加入正確文字

把無字圖放進 Google Slides、Canva 或 PowerPoint，再加入：

- 書名、作者、頁碼。
- 經核對的旁白與對白。
- 族語、姓名、單位名稱或其他正式文字。
- 必要的來源與草稿狀態說明。

文字必須是可選取、可修改的文字層，不能只存在圖片裡。

## Step 8｜交換驗收，只修最大問題

把下列資料交給同學或另一個新對話：

- 原始來源或事實包。
- 角色、場景、畫風與文化卡。
- 該頁繪圖工單。
- 成品頁。
- `criterion.yaml`。

驗收格式：

| 項目 | PASS／FAIL | 成品證據 | 來源／規格證據 | 最小修正 |
|---|---|---|---|---|
| 角色一致 |  |  |  |  |
| 故事忠實 |  |  |  |  |
| 場景與道具 |  |  |  |  |
| 構圖與文字留白 |  |  |  |  |
| 畫風一致 |  |  |  |  |
| 圖內無重要文字 |  |  |  |  |
| 文化／語言／授權 |  |  |  |  |

若 FAIL，只寫出失敗頁最重要的一個修正工單；時間足夠才重生。同一頁最多重試 3 次。AI 通過不等於可以公開，仍需由適合的人確認文化、語言、權利與最後品質。

## 下課前打包

### 三個人工作業關卡

- [ ] Gate 1：來源與權利可繼續；已記錄確認人、日期與待確認項目。
- [ ] Gate 2：作者已核准節拍、不可改寫內容與允許創作空間。
- [ ] Gate 3：已決定「僅課堂草稿」或「允許公開」；沒有具名權責人員核准時只能選前者。

```text
00-來源與授權/
01-故事與YAML/
02-參考圖/
03-生成圖片/
04-排版源稿/
05-驗收紀錄/
06-匯出成品/
```

### 交件檢查

- [ ] `source-pack.md` 有來源與待確認項目。
- [ ] `story-beats.md` 與 4-6 頁分頁規劃完成。
- [ ] 至少保存內容、視覺、權利／文化紅線與單頁工單 YAML；驗收與紀錄可沿用公版。
- [ ] 至少 1 張頁面已完成無字圖、排版與驗收；若完成三張則另行標記。
- [ ] 有可編輯排版源稿與 PDF 預覽。
- [ ] 每張圖可追到提示詞、版本與驗收結果。
- [ ] 尚未完成的語言／文化／授權審訂已標示，不誤稱正式成品。
