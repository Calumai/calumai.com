# NotebookLM 教師直接使用範例

本講義沿用老師熟悉的 NotebookLM 名稱。Google 已將產品現行名稱改為 Gemini Notebook，官方說明網址也已改用 `gemininotebook`。

## 先選來源，再選一個任務

1. 只加入這次教學需要的課綱、教材、教師手冊、投影片或去識別資料。
2. 在來源清單勾選本次要使用的檔案。
3. 從 T01-T10 選一組，不用全部貼。
4. T01-T07、T10 貼在聊天區；T08、T09 貼在 Studio 對應功能的自訂欄。
5. 檢查引用並回到原始來源核對，再由老師決定是否採用。

完整可複製文字請使用同資料夾的 `prompt-library.md`。

## 十種老師常用情境

| 代碼 | 用途 | 建議先加入的來源 | 貼在哪裡 | 會得到什麼 |
| --- | --- | --- | --- | --- |
| T01 | 一堂課快速備課 | 課綱、教材章節、教師手冊、教學時間 | 聊天區 | 學習目標、分鐘流程、提問、檢核與備援活動 |
| T02 | 三種閱讀支援 | 同一份教材、核心目標、鎖定詞彙 | 聊天區 | 鷹架、標準、延伸三條路徑，核心概念保持一致 |
| T03 | 學習單與答案 | 教材、指定範圍、作答時間 | 聊天區 | 學生版題目、教師答案、評分重點與來源引用 |
| T04 | 匿名評量診斷 | 題目、答案規準、去識別的全班彙整結果 | 聊天區 | 迷思假設、資料限制、10 分鐘補救與離堂檢核 |
| T05 | 代課交接單 | 課表、教案、班級規則、設備說明 | 聊天區 | 一頁式流程、材料、備援與待原任教師補充事項 |
| T06 | 核心詞彙表 | 教材、核准詞彙、語言或文化審訂稿 | 聊天區 | 正確拼寫、白話說明、混淆詞與不可改寫事項 |
| T07 | 分層討論題 | 課文、圖表、指定閱讀 | 聊天區 | 找證據、連關係、做判斷三層問題及教師追問 |
| T08 | 教師備課音訊 | 本課全部核准來源 | Studio 的 Audio Overview 自訂欄 | 教師課前預聽、來源衝突、資料缺口與備課檢查題 |
| T09 | 測驗與字卡 | 講義、投影片、考試範圍、鎖定詞 | Studio 的 Quizzes 或 Flashcards 自訂欄 | 可回查來源的理解、因果與證據練習 |
| T10 | 分享前安全檢查 | 預計分享的來源及已生成產物 | 聊天區 | 個資、授權、未公開資訊與文化敏感內容盤點 |

## 三條直接可用的老師路線

### 明天就要上課

1. 加入課綱、課文和教師手冊。
2. 使用 T01 產生第一版備課卡。
3. 使用 T03 產生學習單與答案。
4. 回到引用核對關鍵答案，刪除不適合班級的活動。

### 班上同一單元需要不同支援

1. 加入同一份核准教材和核心學習目標。
2. 使用 T02 產生三種閱讀支援。
3. 確認三組仍學相同核心概念，不用學生姓名或固定能力標籤分組。
4. 只調整句長、步驟、詞彙提示與推論深度。

### 小考後想安排補救

1. 先移除姓名、座號、學號及可識別內容。
2. 加入題目、答案規準與全班彙整結果。
3. 使用 T04 找出有證據的共同問題和資料不能支持的結論。
4. 由老師查看原始作答，再決定是否採用補救活動。

## 不要直接上傳

- 學生姓名、座號、學號、聯絡方式或可識別個人的完整作品。
- 醫療、家庭、輔導、特殊教育或行為紀錄。
- 沒有使用權限的完整教材、測驗卷或付費內容。
- 未經權利人同意的語言、文化、祭儀、傳統知識或社群內部資料。
- 尚未公告的校務資料、帳號密碼、金鑰或內部連結。

## 功能與帳號提醒

- 聊天回答以目前勾選來源為核心並提供引用，仍可能出錯，老師要回看原文。
- Audio Overview、Quizzes、Flashcards、Mind Maps、Slide Deck 等 Studio 功能，會依帳號、年齡、地區、管理員設定與方案而不同。
- Google Classroom 可由老師附加筆記本，但學生實際可用功能仍受學校管理設定影響。
- 公開或班級分享前，要另行確認著作權、學生個資、未公開資料與文化權利。
- 「可以產生」不等於「可以公開」。
