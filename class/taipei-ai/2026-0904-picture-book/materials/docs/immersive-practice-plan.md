# 北市府 AI 繪圖課｜沉浸式練習網頁規劃

## 一、課程定位

本堂課採用「單堂完成型」設計。

學員不是先聽完 AI 繪圖理論，再另外做作業，而是從課程一開始就進入一個「AI 繪本創作工作室」，一路完成自己的作品。

### 最終成果

在一堂課內完成：

- 一本 4-6 頁的 AI 小繪本
- 一組固定角色設定
- 一組固定美術風格
- 一份 4-6 格分鏡腳本
- 每頁的 AI 圖像 Prompt
- 一組完成的繪本頁面

## 二、核心教學目標

本堂課真正要教的不是「做繪本」本身，而是透過繪本製作，讓學員學會四個 AI 繪圖核心能力：

1. 如何描述圖片
2. 如何控制畫風與構圖
3. 如何維持角色一致性
4. 如何從失敗圖片反推 Prompt 要怎麼修改

繪本只是用來承載學習成果的形式。

## 三、整體課程流程

建議將沉浸式網頁設計成六個工作區：

```text
01 故事室
↓
02 角色室
↓
03 美術室
↓
04 分鏡桌
↓
05 生圖室
↓
06 出版桌
```

## 四、網站介面架構

沉浸式頁面不應像資料庫或提示詞清單。比較適合做成「作品逐步長出來」的體驗：

```text
左側：作品進度
中間：目前任務操作區
右側：我的繪本作品牆
```

左側永遠顯示目前到第幾關，讓學員知道自己不是迷路，而是在完成作品流程。

中間只放當前步驟需要操作的內容，避免一次看到太多表單。

右側逐步累積故事種子、角色設定、美術規格、分鏡、圖片提示詞與生成結果。

## 五、六個工作區內容

### 01 故事室

用途：選一個真正想完成的繪本題目。

學員輸入或選擇：

- 教學對象
- 故事主題
- 想傳達的情感
- 是否放入族語或文化元素
- 需要避開或查證的內容

產出：

- 故事種子
- 教學對象
- 文化與授權提醒

### 02 角色室

用途：建立可以重複出現的角色。

學員設定：

- 主角名稱
- 年齡或身分
- 外觀特徵
- 個性
- 重要物件
- 不能亂畫的服飾、圖紋或文化元素

產出：

- 固定角色卡
- 角色一致性檢查表

### 03 美術室

用途：決定整本繪本的視覺方向。

學員選擇：

- 繪本風格
- 漫畫風格
- 色彩氣氛
- 線條感
- 留白方式
- 不要出現的元素

產出：

- 固定美術風格
- 每頁都會沿用的視覺規格

### 04 分鏡桌

用途：把故事拆成 4-6 頁。

每頁至少包含：

- 這一頁發生什麼
- 誰在畫面裡
- 角色在哪裡
- 主要動作
- 背景
- 留白位置
- 不要出現的內容

產出：

- 4-6 頁分鏡腳本

### 05 生圖室

用途：一次處理一個場景，生成無字候選圖。

學員操作：

- 選擇要生成的頁面
- 上傳參考圖，可選
- 檢查 Prompt
- 讓 AI 協助檢視 Prompt
- 生成候選圖
- 記錄失敗原因與修改方向

產出：

- 單頁候選圖
- 修正後 Prompt
- 失敗圖檢討紀錄

### 06 出版桌

用途：整理成果，不急著公開。

學員檢查：

- 角色是否一致
- 圖片是否有文字、水印或錯誤符號
- 文化元素是否需要再次確認
- 圖片是否可以用於課堂
- 是否只作為草稿

產出：

- 繪本草稿包
- 圖片 Prompt 包
- 後續修正清單

## 六、下半堂 NotebookLM 教材轉換

NotebookLM 放在下半堂，不作為另一堂工具課，而是把上半堂完成的故事與圖像素材轉成教師教材。

建議任務：

- 把繪本故事轉成教學簡報
- 把故事角色與關係轉成資訊圖表
- 把繪本內容轉成閱讀引導
- 把故事重點轉成學習單
- 把學生作品整理成分享前檢查表

## 七、三小時課堂節奏

```text
19:00-19:15 進入任務，看範例成品
19:15-19:35 故事室：建立故事種子
19:35-19:55 角色室：固定角色設定
19:55-20:15 美術室：固定畫風、構圖與禁忌
20:15-20:35 分鏡桌：產生 4-6 頁分鏡
20:35-20:50 生圖室：挑一頁生成候選圖
20:50-21:00 休息與整理
21:00-21:30 NotebookLM：生成教學簡報
21:30-21:50 NotebookLM：生成資訊圖表
21:50-22:10 教材整理：閱讀引導或學習單
22:10-22:25 出版桌：檢查與匯出
22:25-22:30 分享與收尾
```

## 八、第一堂課要避免的事

- 不要一開始就講太多工具功能。
- 不要把提示詞庫當主角。
- 不要讓學員同時面對十幾個欄位。
- 不要要求一次完成整本成熟作品。
- 不要把 NotebookLM 跟圖片生成混在同一個操作區。
- 不要讓 AI 代替老師判斷文化、授權與學生適切性。

## 九、第一堂課真正要留下的能力

學員離開教室時應該知道：

- 圖片生成不是抽獎，而是可以用角色、畫風、構圖、留白與禁忌去控制。
- 多頁作品要先固定設定，再逐頁生成。
- 失敗圖片不是浪費，而是用來反推 Prompt 的材料。
- NotebookLM 可以把已完成的故事素材轉成老師更常用的簡報與資訊圖表。
- AI 作品進教室前，仍需要真人檢查來源、文化、授權與適齡性。
