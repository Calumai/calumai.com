今天帶走 一個測過、修過、能交給學生的作品

LESSON 03

從好玩，到真的有學習

先把第一版玩壞、說清楚問題，再加入高一層的思考任務，最後才發布。

  1. 01　先測再修

    把問題說到 AI 聽得懂

    不要只說「壞掉了」。說出期待、實際結果、重現步驟與哪些地方不能改。

    真正的 Vibe Coding
    做、玩、找問題、改、再玩
    修正原則
    一次只改一件事
    組出修正指令
  2. 02　再往上走

    加入分析、評鑑或創造

    從記得答案，走向找線索、做判斷與組出自己的作品。

    這堂重點
    分析、評鑑、創造
    一次只加
    一種能力、一個玩法
    選擇進階關卡
  3. 03　交給學生

    預覽、發布、放進協作平台

    分清楚遊戲原稿、公開網址與教材網站，最後用手機和無痕視窗驗收。

    教材入口
    Google 協作平台
    完成標準
    學生不用登入也能開始玩
    選擇發布方式

PART 01

第一版不完美很正常，重點是怎麼修

影片裡的 3D 遊戲也是先做出能動的版本，再實際試玩、找到跳躍與碰撞問題，最後請 AI 一輪一輪修正。

  1. 01我原本期待按下去應該發生什麼
  2. 02實際發生現在看見什麼
  3. 03怎麼重現從哪一步開始會出錯
  4. 04不要改動哪些內容和功能要保留
選一個最像的問題

按了按鈕，畫面完全沒變

先記下是哪一個畫面、哪一顆按鈕，以及按下前後看到什麼。

補完括號後貼給 AI

              

            

          

        


        

          修完不代表完成
          
回到開始畫面，再完整玩一次。新問題消失，而且原本能用的功能沒有壞，這次修改才算過關。

            04　分析
            
對話偵探

            
提供三段老師核對過的對話與線索，請學生找出哪一句用錯人物或情境。

            學生要比較與說明，不是只猜答案。
          

          

            05　評鑑
            
分支決策

            
遇到不同對象與場合，學生選擇一種回應，再依老師給的標準說明理由。

            文化判斷由老師提供，AI 不自訂規則。
          

          

            06　創造
            
對話建造

            
學生從老師提供的詞句庫中挑選與排序，完成一段可以播放或朗讀的短對話。

            重組已確認內容，不讓 AI 發明族語。

PART 03

          
作品做好以後，才把它放進教材網站

          
Google 協作平台是教材入口。你的遊戲可以貼程式碼、嵌入公開網址，或改成按鈕另開。

        


        
    
          
  1. 01完成遊戲保留 index.html
    2. 
          
  2. 02自己預覽從頭玩完
    3. 
          
  3. 03選放法程式碼或網址
    4. 
          
  4. 04放進 Sites嵌入或按鈕
    5. 
          
  5. 05發布網站取得教材網址
    6. 
          
  6. 06學生測試手機與無痕視窗
    7. 
        


        

          

            
            
            
          

          

            方法 A
            
插入 → 嵌入 → 嵌入程式碼

            
    
              
  1. 在 Google 協作平台右側按「插入」。
    2. 
              
  2. 按「嵌入」，再切換到「嵌入程式碼」。
    3. 
              
  3. 貼上 HTML。CSS 要放在 style 標籤裡，JavaScript 要放在 script 標籤裡。
    4. 
              
  4. 按「下一步」確認預覽，再按「插入」。
    5. 
            

            
完整 HTML 貼不進去時，請 AI 幫你整理成「Google Sites 可嵌入的程式碼片段」，不要自己硬拆。

          

          

            方法 B
            
插入 → 嵌入 → 貼上公開網址

            
    
              
  1. 先用無痕視窗確認遊戲網址真的能開。
    2. 
              
  2. 在 Google 協作平台右側按「插入」，再按「嵌入」。
    3. 
              
  3. 貼上遊戲網址，確認預覽後按「插入」。
    4. 
              
  4. 拉大嵌入區塊，實際點按遊戲按鈕。
    5. 
            

            
有些網站會禁止被嵌入。這不是你操作錯，也不一定是程式壞掉。

          

          

            方法 C
            
改放一顆清楚的按鈕，讓學生另開遊戲

            
    
              
  1. 在右側按「插入」，再按「按鈕」。
    2. 
              
  2. 名稱寫清楚，例如「開始族語問候闖關」。
    3. 
              
  3. 貼上遊戲的公開網址，再按「插入」。
    4. 
              
  4. 發布後，用手機點按鈕測一次。
    5. 
            

            
能順利使用比一定要嵌在頁面裡更重要。

          

        


        

          

            Google 協作平台
            
把遊戲整理成學生找得到的教材頁

          

          
    
            
  1. 01
    開啟 Google 協作平台
    到 sites.google.com，開啟現有網站，或按空白範本建立新網站。
    2. 
            
  2. 02
    新增「小遊戲」頁面
    右側切到「頁面」，按新增頁面，名稱直接寫學生看得懂的用途。
    3. 
            
  3. 03
    加入一句任務說明
    只寫學生要做什麼、完成幾關，不要把製作過程全貼上去。
    4. 
            
  4. 04
    嵌入遊戲或放按鈕
    依照上方 A、B、C 選一種能正常操作的方法。
    5. 
            
  5. 05
    先按預覽
    切換電腦、平板與手機畫面，確認文字、按鈕與遊戲範圍。
    6. 
            
  6. 06
    按發布，設定網址與觀看權限
    若是學校帳號，可用的公開範圍可能由管理員限制。
    7. 
            
  7. 07
    用無痕視窗開正式網址
    不要只在自己的登入狀態測試，還要請另一個人真的玩一次。
    8. 
            
  8. 08
    修改後記得再發布
    編輯畫面已經改好，不代表學生立刻看得到新版。
    9. 
          

        


        

          
分享前最後確認0 / 8
