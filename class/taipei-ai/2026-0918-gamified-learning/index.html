PART 01

第一版不完美很正常，重點是怎麼修

影片裡的 3D 遊戲也是先做出能動的版本，再實際試玩、找到跳躍與碰撞問題，最後請 AI 一輪一輪修正。

  1. 01我原本期待按下去應該發生什麼
  2. 02實際發生現在看見什麼
  3. 03怎麼重現從哪一步開始會出錯
  4. 04不要改動哪些內容和功能要保留
選一個最像的問題

按了按鈕，畫面完全沒變

先記下是哪一個畫面、哪一顆按鈕，以及按下前後看到什麼。

補完括號後貼給 AI

              

            

          

        


        

          修完不代表完成
          
回到開始畫面，再完整玩一次。新問題消失，而且原本能用的功能沒有壞，這次修改才算過關。

            04　分析
            
對話偵探

            
提供三段老師核對過的對話與線索，請學生找出哪一句用錯人物或情境。

            學生要比較與說明，不是只猜答案。
          

          

            05　評鑑
            
分支決策

            
遇到不同對象與場合，學生選擇一種回應，再依老師給的標準說明理由。

            文化判斷由老師提供，AI 不自訂規則。
          

          

            06　創造
            
對話建造

            
學生從老師提供的詞句庫中挑選與排序，完成一段可以播放或朗讀的短對話。

            重組已確認內容，不讓 AI 發明族語。

PART 03

          
用 GAS 把 index.html 變成學生打得開的網址

          
Google Apps Script，簡稱 GAS。這裡把它當成「幫小遊戲取得網路門牌的 Google 工具」，照順序貼好兩個檔案就能發布。

        


        

          

            你的作品
            index.html
            
AI 幫你做好的完整遊戲

          

          →
          

            上線工具
            Apps Script
            
放入 Code.gs 與 index.html

          

          →
          

            學生入口
            /exec 網址
            
用預定學生帳號或無痕視窗驗收

          

        


        

          

            
            
            
            
            
          


          

            

              
STEP 1
建立一個新的 Apps Script 專案

              開啟 Apps Script
            

            
    
              
  1. 開啟 script.google.com，使用放教材的 Google 帳號登入。
    2. 
              
  2. 按「新增專案」。
    3. 
              
  3. 點左上角「未命名的專案」。
    4. 
              
  4. 輸入作品名稱，例如「族語單字翻牌練習」，再按「重新命名」。
    5. 
            

            
看到這樣就成功
左側有 Code.gs，中間出現程式編輯區。

            
進不去嗎？學校帳號可能限制 Apps Script。先不要繞過管理規定，可以改用協作平台直接嵌入，或請管理員協助。

          


          

            

              
STEP 2
在 Code.gs 放入開啟網頁的指令

            

            
    
              
  1. 點左側的 Code.gs。
    2. 
              
  2. 在中間按 Ctrl + A 全選，再按 Backspace 刪除原本內容。
    3. 
              
  3. 複製下方內容，完整貼上。
    4. 
              
  4. 按 Ctrl + S 儲存。
    5. 
            

            

              
直接複製Code.gs

              
              
function doGet() {
  return HtmlService.createHtmlOutputFromFile('index')
    .setTitle('族語單字翻牌練習');
}

              

            

            
這四行在做什麼？
有人打開網址時，請 Google 顯示名為 index 的網頁。

          


          

            

              
STEP 3
新增 index.html，放進完整遊戲

            

            

              
    
                
  1. 在左側「檔案」旁按加號，再選「HTML」。
    2. 
                
  2. 名稱只輸入小寫的 index，不要再加 .html。
    3. 
                
  3. 打開新出現的 index.html。
    4. 
                
  4. 按 Ctrl + A 全選預設內容，再貼上 AI 產生的完整 HTML。
    5. 
                
  5. 如果最上面或最下面有三個反引號，請把反引號刪掉。
    6. 
                
  6. 按 Ctrl + S 儲存。
    7. 
              

              

                檔案
                Code.gs
                index.html
                左側看到這兩個檔案就對了
              

            

            
如果圖片、音檔或外部程式使用 http://，請改成 https://，不然放進 Apps Script 後可能載入失敗。

          


          

            

              
STEP 4
部署成「網頁應用程式」

            

            
    
              
  1. 按右上角「部署」，再選「新增部署作業」。
    2. 
              
  2. 點「選取類型」旁的設定圖示，選「網頁應用程式」。
    3. 
              
  3. 說明可輸入「第一版族語翻牌練習」。
    4. 
              
  4. 「執行身分」選擇自己。
    5. 
              
  5. 「誰可以存取」依學生的帳號範圍選擇。若教材適合公開，而且帳號有提供公開選項，才選可讓一般學生開啟的範圍。
    6. 
              
  6. 按「部署」，第一次使用時依畫面完成必要授權。
    7. 
              
  7. 複製完成畫面中的「網頁應用程式網址」。
    8. 
            

            
完成標準
拿到一個以 /exec 結尾的網址，並先把它保存起來。

            
沒有「任何人」之類的公開選項，通常是學校或機關帳號的管理規定。不要一路亂按，也不要嘗試繞過限制。

          


          

            

              
STEP 5
先測正式網址，再交給學生

            

            
    
              
  1. Chrome 按 Ctrl + Shift + N 開啟無痕視窗。
    2. 
              
  2. 貼上剛才的網頁應用程式網址。
    3. 
              
  3. 從開始畫面一路玩到結果畫面。
    4. 
              
  4. 如果學生預計不用登入，確認無痕視窗也沒有要求登入。
    5. 
            

            

              
只拿來測試/dev
只有可以編輯專案的人能開，會顯示最新儲存內容。

              
交給學生/exec
正式部署網址。先確認權限，再放進協作平台。

            

            

              遊戲改好了，學生怎麼看到新版？
              
先儲存，再到「部署 → 管理部署作業」，選原本的部署、按編輯、建立新版本後重新部署。沿用同一個部署時，網址通常不用重貼。

            

          

        


        

          操作依據
          Google：部署與嵌入 Web App
          Google：更新既有部署
          Google：HTML 服務限制
        

      

    


    

      

        

          
PART 04

          
網址測過以後，再放進教材網站

          
Google 協作平台是教材入口。GAS 負責讓遊戲有網址，協作平台負責把課程說明、影片、教材與遊戲整理在一起。

    2. 
          
  2. 02放進 GAS準備兩個檔案
    3. 
          
  3. 03部署 Web App取得 /exec 網址
    4. 
          
  4. 04無痕測試確認學生能開
    5. 
          
  5. 05放進 Sites嵌入或按鈕
    6. 
          
  6. 06發布再測手機完整玩一次

            方法 A
            
插入 → 嵌入 → 嵌入程式碼

            
    
              
  1. 在 Google 協作平台右側按「插入」。
    2. 
              
  2. 按「嵌入」，再切換到「嵌入程式碼」。
    3. 
              
  3. 貼上 HTML。CSS 要放在 style 標籤裡，JavaScript 要放在 script 標籤裡。
    4. 
              
  4. 按「下一步」確認預覽，再按「插入」。
    5. 
            

            
完整 HTML 貼不進去時，請 AI 幫你整理成「Google Sites 可嵌入的程式碼片段」，不要自己硬拆。

          

          

            方法 B
            
插入 → 嵌入 → 貼上 GAS 的 /exec 網址

            
    
              
  1. 先用無痕視窗確認 /exec 網址真的能開。
    2. 
              
  2. 在 Google 協作平台右側按「插入」，再按「嵌入」。
    3. 
              
  3. 貼上 GAS 的網頁應用程式網址，確認預覽後按「插入」。
    4. 
              
  4. 拉大嵌入區塊，實際點按遊戲按鈕。
    5. 
            

            
網址本身能開、嵌入後卻要求登入時，先檢查 GAS 的部署存取範圍與學校帳號政策。

          

          

            方法 C
            
改放一顆清楚的按鈕，讓學生另開遊戲

            
    
              
  1. 在右側按「插入」，再按「按鈕」。
    2. 
              
  2. 名稱寫清楚，例如「開始族語問候闖關」。
    3. 
              
  3. 貼上遊戲的公開網址，再按「插入」。
    4. 
              
  4. 發布後，用手機點按鈕測一次。
    5. 
            

            
能順利使用比一定要嵌在頁面裡更重要。

          

        


        

          

            Google 協作平台
            
把遊戲整理成學生找得到的教材頁

          

          
    
            
  1. 01
    開啟 Google 協作平台
    到 sites.google.com，開啟現有網站，或按空白範本建立新網站。
    2. 
            
  2. 02
    新增「小遊戲」頁面
    右側切到「頁面」，按新增頁面，名稱直接寫學生看得懂的用途。
    3. 
            
  3. 03
    加入一句任務說明
    只寫學生要做什麼、完成幾關，不要把製作過程全貼上去。
    4. 
            
  4. 04
    嵌入遊戲或放按鈕
    依照上方 A、B、C 選一種能正常操作的方法。
    5. 
            
  5. 05
    先按預覽
    切換電腦、平板與手機畫面，確認文字、按鈕與遊戲範圍。
    6. 
            
  6. 06
    按發布，設定網址與觀看權限
    若是學校帳號，可用的公開範圍可能由管理員限制。
    7. 
            
  7. 07
    用無痕視窗開正式網址
    不要只在自己的登入狀態測試，還要請另一個人真的玩一次。
    8. 
            
  8. 08
    修改後記得再發布
    編輯畫面已經改好，不代表學生立刻看得到新版。
    9. 
          

        


        

          
分享前最後確認0 / 10
