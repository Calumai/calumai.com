# 師大 Vibe Coding 互動課程頁

這個獨立頁面把 `20260825-師大課程.pptx` 的 57 張投影片，整理成六個可操作的學習模組。

## 路由與檔案

- 預定公開路由：`/class/ntnu-20260825/`
- 頁面：`index.html`
- 視覺與響應式規則：`styles.css`
- 互動與本機進度保存：`app.js`
- 原始簡報：`assets/20260825-師大課程.pptx`
- 投影片圖片：`assets/slides/slide-1.png` 至 `slide-57.png`

## 六個互動

1. 老師與 AI 的角色分類
2. 四問藍圖產生器
3. MVP 版本排序
4. 族語聽力流程拼圖
5. HTML、CSS、JavaScript 網站透視鏡
6. 安全修改與上線流程排序

頁面另含完整投影片瀏覽器、淺色與深色模式、手機版排版，以及使用 `localStorage` 保存的學習進度。

## 本機預覽

在部署專案根目錄啟動靜態伺服器：

```powershell
python -m http.server 4174
```

然後開啟 `http://127.0.0.1:4174/class/ntnu-20260825/`。
