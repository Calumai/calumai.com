太魯閣語 2026 年公告版詞表請到原住民族語學習詞表系統下載：
https://glossary.ilrdf.org.tw/

下載 Excel 後，請先另存為 Google 試算表，在最左側新增「啟用」欄，
要讓 LINE 查到的資料列填「是」，並把工作表名稱改為「單詞列表」。

重要提醒
1. 程式內沒有 LINE Token。
2. 請在 Apps Script「專案設定 → 指令碼屬性」建立 LINE_TOKEN。
3. 行事曆與單詞是兩套獨立程式；若兩個都要保留，請使用兩個練習用 LINE 官方帳號。
4. 不要把 Token、Channel secret、綁定碼、完整 /exec 網址或私人資料放進公開作業。
5. 官方詞表版權與使用條件依來源網站標示；本站素材包不另外重製詞料檔。
