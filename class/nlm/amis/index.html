怎麼做成自己的版本？

  1. 把教材放入 NotebookLM。這次因本機 PDF 上傳受瀏覽器設定限制，我們將 PDF 文字按頁貼成兩個來源。
  2. 只勾選要用的那份來源，點「工作室 → 資訊圖表」，貼上對應提示詞。
  3. 圖片完成後，逐句對照原 PDF，再下載 PNG。想換形式，可以改提示詞中的「五個關卡」或「五張線索卡」，例如改成賓果格、尋寶路線或配對卡。
