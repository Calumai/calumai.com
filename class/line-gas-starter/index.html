這個範例完成後會做什麼？

老師維護一份 Google 試算表；學生只要在 LINE 傳短指令，就能看到老師提供的內容。

📅 課程行事曆

學生傳「行事曆」，查看試算表中接下來的課程。老師直接編輯「行事曆」分頁。

🎲 隨機測驗

學生傳「測驗」抽一題，再傳「答 A」「答 B」或「答 C」看答案與解說。

🔔 自願訂閱通知

學生先傳「訂閱」，老師排定的通知到時才推送；傳「取消訂閱」即可停止。

📖 單詞表

老師在「單詞表」填經審核的詞；學生傳「單詞表」看前五筆，或傳「查單詞 太陽」查特定一筆。

☀️ 每日一句

老師在「每日一句」填當天的族語句子與中文翻譯；學生傳「每日一句」就能閱讀。

這裡的「行事曆」是試算表課表。

本範例不會同步 Google Calendar，學生也不能從 LINE 新增活動。老師想從 LINE 新增課表、單詞、每日一句與通知，可接著做老師專用課務助理；它使用另一個 LINE 官方帳號，表單資料仍寫回同一份試算表。想學真正的 Google 行事曆串接，可看第 8 堂行事曆進階版；20 功能延伸版則是另一份程式。

老師編輯 Google 試算表→Apps Script 讀取與排程→學生在 LINE 查詢或訂閱

照做的步驟：從空白試算表到 LINE 測試

先準備自己的 Google 帳號、測試用 LINE 官方帳號與 Messaging API Channel access token。練習資料請用假名字和中性題目；不要把 Token 貼進程式碼、作業或公開網頁。首次設定完成後，平常只要編輯同一份試算表；新增或修改表格資料不用重新部署。

  1. 建立一份空白 Google 試算表

    開啟 Google 試算表，按「空白試算表」，名稱可填「我的 LINE 教學機器人」。這份表由你自己擁有即可，不用先複製試算表 ID。

    完成後會看到：一份可以編輯的空白試算表。

  2. 從試算表打開 Apps Script，貼上 Code.gs

    在試算表上方點「擴充功能」→「Apps Script」，左側點預設的 Code.gs。先用本頁下方的「複製完整 Code.gs」或下載檔案取得整份程式；回到 Apps Script 編輯區按 Ctrl+A 全選原內容，貼上整份程式，再按 Ctrl+S 儲存。

    完成後會看到：左側只有這一份教學版 Code.gs；不需要再貼 20 功能版或第 8 堂的其他檔案。

  3. 先選 setup，再按「▶ 執行」

    在 Apps Script 畫面上方的「函式」下拉選單選 setup，按旁邊的「▶ 執行」。第一次執行會跳出 Google 授權：先確認這是你自己建立、自己貼入程式的專案，再依畫面選帳號並允許。

    setup 會自動記住這份綁定試算表的 ID、建立七張中文分頁，並放入三題中性示範題。不用手改程式裡的試算表 ID。

    完成後會看到：Apps Script 的執行紀錄顯示完成；回到試算表重新整理，底部出現「學生」「行事曆」「題庫」「通知」「發送紀錄」「單詞表」「每日一句」。

  4. 設定台灣時區和 LINE 權杖

    在 Apps Script 左側點齒輪「專案設定」，將時區選為 Asia/Taipei。往下找到「指令碼屬性」，按「新增指令碼屬性」：名稱填 LINE_ACCESS_TOKEN，值貼入 LINE Developers 的 Messaging API Channel access token，最後按儲存。這裡填的是 Channel access token，不是 Channel secret。

    完成後會看到：指令碼屬性清單有 LINE_ACCESS_TOKEN；權杖不會出現在公開的 Code.gs。

  5. 執行 checkSetup 檢查設定

    回到左側「編輯器」，在上方函式下拉選單改選 checkSetup，按「▶ 執行」。若執行失敗，點開執行紀錄中的錯誤文字：找不到試算表就回第 1～3 步，缺少 Token 就回第 4 步。

    完成後會看到：執行紀錄沒有紅色錯誤，確認這份程式能連到試算表且已設定權杖。

  6. 在同一份試算表填課程、單詞、每日一句

    到「行事曆」分頁的第 2 列，依表頭填 活動ID（例如 C001）、課程名稱、未來的 開始時間、地點、備註、課前 30～60 分鐘的 提醒時間，最後在 啟用 填「是」。兩個時間儲存格要用真正的「日期時間」格式；可選取儲存格，點「格式」→「數字」→「日期時間」。

    再到「單詞表」第 2 列填一個經老師確認的單詞：單詞ID 可填 W001、中文 可填「太陽」，族語 請填正確拼寫，例句 與 例句翻譯 可填老師審核過的內容，音檔網址 沒有就先留白，啟用 填「是」。到「每日一句」第 2 列填今天的日期、經老師確認的 族語句子 與 中文翻譯；音檔網址可留白，啟用填「是」。日期欄要是真正的日期儲存格，可點「格式」→「數字」→「日期」。最後到「題庫」確認已有三題示範題。

    完成後會看到：一堂未來課、至少一個啟用單詞、今天的每日一句，還有三題可測試的題目。

  7. 部署成網頁應用程式，複製 /exec 網址

    回到 Apps Script，右上角點「部署」→「新增部署作業」。點「選擇類型」旁的齒輪，選「網頁應用程式」；「執行身分」選「我」，「誰可以存取」選「所有人」，再按「部署」並完成授權。複製畫面給你的「網頁應用程式網址」，網址結尾應為 /exec。

    完成後會看到：一個可複製的 https://script.google.com/macros/s/…/exec 網址。這是 Webhook 使用的網址，不是本講義網址。

  8. 把 /exec 貼到 LINE Webhook

    打開 LINE Developers，選你的測試用 Messaging API channel，進入「Messaging API」頁。在「Webhook URL」貼入剛才的 /exec，按「Update」儲存，再按「Verify」測試，最後開啟「Use webhook」。同一個 channel 只有一個 Webhook URL；若你覆蓋舊網址，舊機器人就不會再收到該 channel 的訊息。

    完成後會看到：Verify 顯示成功，Use webhook 為啟用。若沒有成功，先核對部署網址、存取權與是否選到最新部署。

  9. 加入官方帳號好友，在一對一聊天測五個功能

    用自己的 LINE 測試帳號加入這個官方帳號好友，依序傳「說明」→「訂閱」→「行事曆」→「單詞表」→「查單詞 太陽」→「每日一句」→「測驗」→「答 A」（或依題目選「答 B」「答 C」）。「測驗」會從啟用的題庫隨機取一題；答題後會回傳正解與解說。再傳「取消訂閱」可停止通知，若還要測試推播，請重新傳「訂閱」。

    完成後會看到：LINE 有課程、前五筆單詞、特定單詞、當日句子、題目與答題回覆；試算表「學生」分頁有你自己的 LINE 使用者 ID 和訂閱狀態。

  10. 執行 installTrigger，建立自動檢查

    回 Apps Script 編輯器，上方函式選單選 installTrigger，按「▶ 執行」並完成要求的授權。程式會建立定時觸發器，約每 15 分鐘檢查一次到期的「通知」和課程提醒；不保證剛好在整點送達。你也可以點左側時鐘「觸發條件」查看是否建立成功。這份範例每次最多嘗試推播 20 則，適合小班測試；人數較多時請把提醒排在課前 30～60 分鐘，並查看「發送紀錄」。課程開始後，未排到的提醒不會補送。

    完成後會看到：觸發條件清單出現執行通知檢查的時間觸發器。重跑 installTrigger 不應建立重複觸發器。

  11. 填一筆測試通知，手動執行 sendDueNotifications

    確認自己的 LINE 帳號仍是「訂閱」狀態。到試算表「通知」分頁第 2 列，依序填 通知ID（例如 N001）、發送時間（測試時填現在稍早、未超過 24 小時的真正日期時間）、內容（例如「測試提醒：請查看課表」）、啟用（填「是」）。回 Apps Script 函式選單選 sendDueNotifications，按「▶ 執行」。

    完成後會看到：訂閱中的測試帳號應收到 LINE 推播；「發送紀錄」新增來源 ID、LINE 使用者 ID、發送時間與結果。同一筆成功紀錄可幫助程式避免重複推送，但仍請用自己的 LINE 聊天畫面確認。

以後改了 Code.gs，要重新部署版本。

按 Ctrl+S 儲存後，到「部署」→「管理部署作業」→鉛筆「編輯」→選「新增版本」→「部署」。只按儲存，不會讓既有 /exec 自動換成新版程式。

已經裝過舊版入門程式？

從本頁重新取得完整 Code.gs，在原本的 Apps Script Code.gs 全選取代並儲存；再執行一次 setup，讓原本同一份試算表增加「單詞表」「每日一句」，既有五張分頁資料不會被清空。接著依上方方式到「管理部署作業」選「新增版本」部署，原本的 Webhook 網址可繼續使用。新增或改動表格內容則不用再部署。

已經完成設定，想從試算表立即發送？

另加一個 ImmediateSend.gs，就能在「通知」分頁選取一列，從「LINE 通知 → 立即發送選取的通知」點按並確認。這個檔案加在原本與學生試算表連動的 Apps Script 專案；你現有的 Code.gs 不用改，老師助理的 Code.gs 也不用改。

學生在 LINE 要傳什麼？

說明列出可用指令。
訂閱同意接收這個官方帳號的課程／公告提醒。
取消訂閱停止接收後續主動推播。
行事曆查看老師在試算表填的未來課程。
單詞表列出前五筆啟用的單詞，並提示如何查特定詞。

測驗從啟用的題庫隨機抽一題。

老師只在同一份試算表維護課程、題庫、通知、單詞和每日一句；這個版本沒有從 LINE 發全班公告的管理指令。修改試算表資料不必重新執行 setup 或重新部署。

每日一句是學生主動查詢。它不會每天自動推播。若老師想提醒已訂閱的學生來看，可另外在「通知」分頁填一則到期通知。

遇到問題，先檢查這裡

函式選單找不到 setup？

確認整份 Code.gs 都已貼入並按 Ctrl+S。若貼到獨立建立的 Apps Script 專案，請回到自己的試算表，從「擴充功能 → Apps Script」重新開啟綁定專案。

setup 執行成功，但找不到七張分頁？

回到原本的試算表頁籤重新整理，查看底部分頁。「setup」只能在由該試算表開啟的綁定專案執行；不要混用其他 Google 帳號的試算表。已裝舊版的人要先換成此頁的新版 Code.gs，再執行一次 setup。

LINE Verify 失敗，或傳訊息沒回覆？

確認 Webhook URL 結尾是 /exec、部署類型是「網頁應用程式」、執行身分是「我」、存取權是「所有人」，再查看 Apps Script「執行項目」的 doPost 紀錄與 LINE 權杖設定。若改過程式，還需新增部署版本。

行事曆顯示沒有課程？

檢查「行事曆」分頁是否有未來的開始時間、時間儲存格是否為日期時間格式，並確認該列「啟用」為「是」。這裡不讀取 Google Calendar。

查單詞找不到？

請傳「查單詞」加空格再加表內有的中文、族語或單詞 ID，例如「查單詞 太陽」。檢查「單詞表」有沒有這筆資料，且「啟用」為「是」。老師新增或改表格內容後，不用再部署。

每日一句沒有顯示今天的內容？

檢查「每日一句」分頁有沒有今天的日期、族語句子及中文翻譯，「啟用」是否填「是」，日期欄是否為真正的日期儲存格。也請確認試算表與 Apps Script 時區都是 Asia/Taipei。

測驗後傳答 A 沒反應？

先傳「測驗」取得題目，再傳「答 A」「答 B」或「答 C」。測驗暫存在 GAS 快取中，可能提早消失；看到題目過期訊息時，重新傳「測驗」即可。也請檢查「題庫」有啟用的題目、正解填 A／B／C。

一個指令收到兩則回覆？

測試用官方帳號若同時開啟 LINE Official Account Manager 內建的「自動回應訊息」或「加入好友歡迎訊息」，可能與 GAS 回覆一起出現。練習期間可先到管理後台關閉這兩項，再測試 Webhook 回覆。

通知到時間卻沒有收到？

先確認測試帳號已加好友、仍在「訂閱」狀態，老師已執行 installTrigger，該列「啟用」為「是」且時間為日期時間格式。看「發送紀錄」與 Apps Script「執行項目」查原因；自動觸發約每 15 分鐘檢查一次，不保證整點送達。

教學使用範圍

  • 這是讓學生照做的課堂測試範例。GAS 直接接 LINE Webhook 無法讀取並驗證 X-Line-Signature 標頭，無法把收到的事件當作已驗證的 LINE 身分；不要用真實學生個資、成績或重要行事。
  • 只有先加入官方帳號好友並傳「訂閱」的測試帳號，才會列入主動推播。但因 Webhook 來源無法驗證，表中的「訂閱」不是正式的學生同意紀錄；只用假資料與測試帳號。LINE 推播會使用訊息額度；發送前先檢查官方帳號的可用額度。
  • 老師提供的族語單詞、例句、每日一句、題目、答案與文化內容需自行審核；音檔也要確認可公開使用。本範例的中性示範題只用於測試流程，不會憑空產生族語內容。
  • 時間觸發器可能晚於指定分鐘執行；GAS 接收 LINE 訊息也可能因啟動較慢或同時多人操作而延遲。這份範例不保證即時或穩定送達。「發送紀錄」中的「成功」只表示 LINE API 接受請求，不能證明學生實際收到或已讀；若 API 接受後、寫入紀錄前發生錯誤，也可能再次推送。
