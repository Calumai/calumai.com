課程總覽 ／ 學生版 LINE × GAS ／ 立即發送通知

已經建好機器人的老師，從這裡加功能

在試算表選一列，
確認後立即發送 LINE 通知

只新增一個 ImmediateSend.gs 檔案；原本的 Code.gs 和 Webhook 都不用取代。老師與學生共用同一個 LINE BOT。

跟著步驟做下載獨立 .gs 程式

先確認放對地方

這個新增檔案要放在從原 Google 試算表「擴充功能 → Apps Script」開啟的機器人專案。同一個專案保存唯一的 LINE_ACCESS_TOKEN，也有「學生」「通知」「發送紀錄」分頁。

試算表只開放可信任的老師編輯。

這個按鈕由試算表編輯者手動執行；若另加LINE 教師課務功能，老師也能在同一個 BOT 對話中新增排程通知。

新增檔案，再從試算表點發送

  1. 從原試算表打開學生版 Apps Script

    進入目前學生機器人正在使用的 Google 試算表，點上方「擴充功能 → Apps Script」。先確認左側能看到你原本的 Code.gs。

    完成後會看到：原本程式還在，不需要刪除或修改。

  2. 新增一個指令碼檔案

    在 Apps Script 左側「檔案」旁按 ＋，選「指令碼」，名稱輸入 ImmediateSend。打開新檔，貼上本頁下方的完整程式，或下載 ImmediateSend.gs 後用記事本全選複製，按 Ctrl+S 儲存。

    完成後會看到：左側同時有原本的 Code.gs 和新增的 ImmediateSend.gs。

  3. 重新整理試算表，找新選單

    回到原 Google 試算表按 F5 重新整理。上方選單會出現「LINE 通知」。如果首次點選功能出現 Google 授權畫面，使用自己管理試算表的帳號完成授權，再重新點一次。

    完成後會看到：「LINE 通知 → 立即發送選取的通知」。這個試算表工具直接執行目前的 Apps Script 專案，不必重新部署 Webhook 版本。

  4. 在「通知」分頁準備並選取一列

    到「通知」分頁，填好 A：通知ID、C：內容、D：啟用＝是（或勾選核取方塊），再點這一列任一個儲存格。B：發送時間可以先留白或填未來時間；按下立即發送時，程式會把 B 欄改成現在。若之前已執行過 installTrigger，原排程會在此後 24 小時內接續嘗試；沒安裝時可再次手動點選。

    完成後會看到：只有這一列被選取；請先用自己的 LINE 測試帳號傳「訂閱」。

  5. 確認內容與人數，再發送

    點「LINE 通知 → 立即發送選取的通知」。確認視窗會顯示通知 ID、內容及尚待發送的人數；核對無誤才按「是」。程式只處理這一列，不會順便送出其他到期課程提醒。

    完成後會看到：結果視窗列出本次嘗試、LINE API 接受、失敗與尚待發送人數；「發送紀錄」分頁新增或更新逐位學生的結果。

有成功紀錄的對象，重按時會跳過。

每次最多嘗試 20 位；人數更多或有失敗時，可以再按一次。原排程也使用同一組通知 ID 去重。若要發布一則全新的內容，請使用新的通知 ID。LINE API 接受不等於保證學生已讀或實際送達。

想要試算表上看得見的按鈕？

在電腦版 Google 試算表點「插入 → 繪圖」，畫一個寫著「立即發送」的按鈕並儲存。點選這張繪圖右上角的「⋮ → 指派指令碼」，只輸入 sendSelectedNoticeNow，不要加括號。以後先選通知資料列，再點按鈕，同樣會先跳確認視窗。

Google 的繪圖按鈕只會在電腦瀏覽器點擊時執行；手機版請改用電腦操作。選單已可完成同樣的事，不必一定製作繪圖按鈕。
