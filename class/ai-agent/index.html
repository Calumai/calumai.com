族語教師數位教材課程 / AI AGENT

讓 AI Agent 幫你動手做，
教材仍由你把關。

從已有的詞句、題庫和教學目標出發，請 AI 整理、製作、檢查，再由族語教師核對語言與文化內容。下載學生懶人包，就能在自己的練習專案開始。

下載學生懶人包 ZIP看安裝步驟
本章要完成什麼？選一個真實的教學小任務，交給 Agent 處理一部分，最後說清楚它做了什麼、你核對了什麼，以及哪些地方還不能直接拿去教學。

四個可選任務

01 / 備課

整理教學流程

用已確認的詞句、教學對象與目標，做出課堂流程與待確認清單。

02 / 繪本

規劃繪本分鏡

把故事做成 4–6 頁分鏡，族語原文保留，缺少的句子標示待補。

03 / 互動

製作練習網頁

把已核對的題庫做成可在本機打開的互動練習，再試作答與手機畫面。

04 / 檢查

找出教材缺漏

檢查詞卡、題庫、音檔或網站的空白、重複、缺檔及壞連結。

Windows 11：下載後怎麼做

  1. 點上方「下載學生懶人包 ZIP」。在「下載」資料夾對 ZIP 按右鍵，選「全部解壓縮」。
  2. 進入解壓後的資料夾，雙擊 START-HERE.html；畫面會顯示四項任務與起手式。
  3. 若要在 AI 編碼助理中使用，開啟自己建立的練習專案，照包內 README.md 選裝需要的技能。請勿直接修改老師提供的原稿。
  4. 用示範或已獲授權的素材試跑，親自核對族語、答案、音檔與操作結果。

上課前先記住

AI 可以整理資料、製作頁面並指出明確缺漏；族語的拼寫、腔調、語意、發音、文化脈絡與公開授權，仍需由相應教師及權利關係人確認。練習素材不要包含學生個資、帳密或未授權內容。這份素材包不會自動登入服務、安裝付費工具或發布作品。
