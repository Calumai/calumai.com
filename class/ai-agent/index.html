AI Agent 入門指南

從「會聊天」到「會做事」的 AI 助理。先認識 Agent 怎麼運作，再練習交代任務、看懂權限與檢查成果；族語教學的內容判斷，由老師掌握。

下載課堂練習包 ZIP查看六個單元

這堂課學什麼？依 2026 年 10 月 27 日版《AI Agent 入門指南》講義整理，約 3 小時，適合沒有程式經驗的老師。課程以觀念、任務寫法與安全判斷為主；需要動手時，講義以 OpenCode 桌面版示範，安裝細節另見配套的 OpenCode 講義。沒有安裝軟體，也能完成紙筆與記事本練習。

約 3 小時，含休息Windows 10／11零程式基礎可參加

六個單元

01 · 25 分鐘

什麼是 AI Agent？

比較聊天 AI 與會使用工具的 Agent，認識模型、工具、工作迴圈、上下文／記憶與權限五個零件。

02 · 30 分鐘

八個核心觀念

用老師熟悉的例子理解工具呼叫、規劃與執行、MCP、Skills，以及「人在迴路中」的把關方式。

03 · 20 分鐘

認識常見 Agent 類型

分辨寫程式、瀏覽器操作、研究、流程自動化及個人助理五類；產品名稱與功能可能變動，使用前請查官方資訊。

04 · 25 分鐘

怎麼交代任務

把模糊要求寫成「目標、背景、限制、完成標準、檢查點」五格任務單，先讓 Agent 提出計畫。

05 · 20 分鐘

安全與隱私

用權限紅綠燈判斷哪些能做、哪些要先問、哪些留給老師；練習檢查事實、適切性與實際動作。

06 · 30 分鐘

教師應用情境

從講義的十個情境選一個試做，例如教案草稿、分層學習單、教學小工具、研究摘要或重複工作技能。

交代任務時，先寫五格

目標要做什麼，給誰用？
背景學生程度、現有素材與範本。
限制哪些資料與動作不能碰？
完成標準做成什麼樣，如何驗收？
檢查點哪一步先停下來給老師看？

課堂練習包怎麼用

  1. 點上方下載 ZIP，在 Windows 檔案總管對 ZIP 按右鍵，選「全部解壓縮」。
  2. 進入解壓後的資料夾，雙擊 START-HERE.html；先閱讀課程地圖，再開啟 課堂練習.md 做六個練習。
  3. 若要延伸做族語教材，可從四項選用技能挑一項。它們是延伸練習，並非完成本課的必要安裝項目；安裝方式見包內 README.md。
  4. 只用假資料或有權使用的素材試跑，最後親自檢查族語、事實、檔案與操作結果。

老師保留最後把關

學生姓名、成績、聯絡方式、照片與其他可辨識個資不要提供給 AI。寄送訊息、刪檔、付款、登入校務系統等動作由老師親自處理；練習只使用假資料或已獲授權素材。

族語詞句、拼寫、腔調、發音、文化脈絡與公開使用權，仍需由相應的族語教師及權利關係人核對。Agent 說「完成」後，要再看事實、適切性與它實際做了什麼。
