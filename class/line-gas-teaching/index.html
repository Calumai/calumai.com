04｜實作安裝：8 個步驟

  1. 建立 Google 試算表

    新建一份空白試算表，例如「族語教學 LINE 機器人」。從網址 /d/ 和 /edit 之間複製試算表 ID。

  2. 進入 Apps Script

    在試算表選擇「擴充功能 → Apps Script」，刪除預設檔內的示範函式。

  3. 建立四個指令碼檔案

    建立 01_設定與資料庫.gs、02_LINE接收與回覆.gs、03_族語教學功能.gs、04_測試與通知.gs，貼入頁面下方相對應的程式碼。GAS 會將專案中的檔案視為同一個程式環境。

  4. 設定指令碼屬性

    專案設定 → 指令碼屬性：新增 SPREADSHEET_ID 與 LINE_ACCESS_TOKEN。權杖請勿公開或貼到教材頁面。

  5. 建立資料表並測試

    將專案時區設為 Asia/Taipei，執行 setup() 並完成授權，確認已建立 12 張分頁。再執行 testLocally()，查看執行紀錄。

  6. 部署為網頁應用程式

    部署 → 新增部署作業 → 網頁應用程式。執行身分選「我」，誰可以存取選「所有人」，部署並複製末尾為 /exec 的網址。

  7. 設定 LINE Webhook

    在 LINE Developers 的 Messaging API 設定 Webhook URL 為 GAS 的 /exec，啟用 Use webhook，加入機器人好友後傳送「課程」「每日一句」「測驗」。

  8. 修改後重新部署

    修改程式後需到「部署 → 管理部署作業 → 編輯 → 新增版本」，既有 /exec 才會套用最新版程式。

先完成 setup()、testLocally()，確定試算表端正常，再連接 LINE，可大幅減少除錯時間。

09｜常見問題與排除

執行 setup() 顯示找不到試算表？

確認指令碼屬性 SPREADSHEET_ID 只填網址中的 ID，且執行者有存取該試算表的權限。

傳 LINE 訊息沒有回覆？

確認 LINE_ACCESS_TOKEN 有效、Webhook URL 為最新 /exec、使用者已加入官方帳號、Use webhook 已啟用；查看 Apps Script 執行紀錄與 LINE Developers 的 Webhook 驗證結果。

修改 GAS 程式後 LINE 還是舊版本？

既有部署需新增版本，只有儲存程式碼並不代表 /exec 已更新。

查不到單字或題目？

檢查 words 和 questions 的欄位順序有沒有改動、內容是否填在第一列表頭之後，以及是否輸入完全相符的示範指令。

提醒沒有發送？

要先執行 installReminderTrigger() 建立定時觸發器；確認時間為未來台灣時間、官方帳號可發送訊息並具備可用推播額度。

「每日挑戰」輸入答 A 沒有計分？

目前每日挑戰只展示題目，不會建立正式測驗 session。要計分請改用「測驗」取得題目，再輸入「答 A」。

10｜安全限制與正式上線前檢查

重要：這是課堂示範原型，不是正式學生管理系統。

直接將 GAS /exec 當 LINE Webhook 時，GAS 無法存取驗證所需的 X-Line-Signature HTTP 標頭，因此無法確認請求真的來自 LINE。知道網址的人可能偽造事件。

  • 請只用假名字、測試用題目和非敏感資料操作。
  • 不要把 Channel access token、真實學生名單、成績或請假資料放在公開講義。
  • 本範例只預設一個 LINE 官方帳號；不同官方帳號共用資料需要額外的身分綁定和權限設計。
  • LINE 訊息數量和 GAS 執行次數受服務方案及配額限制。
  • 正式上線需增加來源簽章驗證、存取控管、資料備份、防重送、併發安全及個資保護。

02_LINE接收與回覆.gs 點擊展開程式碼
/** LINE 入口：僅作課堂演示。GAS 無法取得 X-Line-Signature 標頭，不能驗證來源。 */
function doPost(e) {
  try {
    if (!e || !e.postData || !e.postData.contents) return response_('EMPTY');
    const payload = JSON.parse(e.postData.contents);
    if (!Array.isArray(payload.events)) return response_('INVALID');
    payload.events.forEach(event => {
      if (event.type !== 'message' || !event.message || event.message.type !== 'text') return;
      if (!event.replyToken || !event.source || !event.source.userId) return;
      const uid = event.source.userId;
      let answer;
      try { answer = command_(String(event.message.text || '').trim(), uid); }
      catch (err) { console.error('command error', err); answer = '系統暫時無法處理，請稍後重試。'; }
      reply_(event.replyToken, answer);
    });
    return response_('OK');
  } catch (error) {
    console.error('webhook error', error);
    return response_('ERROR');
  }
}
function doGet() { return response_('Calumai LINE GAS 教學版已部署'); }
function response_(txt) { return ContentService.createTextOutput(txt); }
function reply_(replyToken, content) { return sendLine_('reply', {replyToken, messages:[{type:'text',text:String(content).slice(0,4900)}]}); }
function push_(userId, content) { return sendLine_('push', {to:userId,messages:[{type:'text',text:String(content).slice(0,4900)}]}); }
function sendLine_(endpoint, body) {
  const token = prop_('LINE_ACCESS_TOKEN');
  if(!token) throw new Error('請設定指令碼屬性 LINE_ACCESS_TOKEN');
  const response = UrlFetchApp.fetch('https://api.line.me/v2/bot/message/' + endpoint, {
    method:'post', contentType:'application/json',
    headers:{Authorization:'Bearer ' + token}, payload:JSON.stringify(body),
    muteHttpExceptions:true
  });
  const code = response.getResponseCode();
  if(code < 200 || code >= 300) throw new Error('LINE API HTTP ' + code + ': ' + response.getContentText());
  return true;
}
