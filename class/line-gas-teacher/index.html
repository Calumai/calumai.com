課程總覽 ／ 第 8 堂 ／ 老師專用課務助理

給已完成學生 LINE 機器人的老師

從 LINE 打開表單，
把課務加進同一份試算表

這是老師自己用的固定指令助理。傳「新增課程」「新增單詞」「新增每日一句」或「新增通知」，開啟只有老師 Google 帳號能填的表單；送出後，學生原本的 LINE 機器人就能讀到新資料。

照步驟安裝下載完整 Code.gs查看程式碼從試算表立即發送
同一份試算表學生機器人與老師助理是兩個獨立 LINE 官方帳號、兩個 Apps Script 專案，但共同使用你原本那份試算表。
本頁目錄先看運作方式安裝步驟老師能說什麼表單送出後立即發送通知權限與限制常見問題完整 Code.gs

先看運作方式

老師在 LINE 傳指令→助理回傳專用表單→老師登入填寫→寫進原試算表→學生機器人讀取
📅 新增課程

填名稱、時間、地點與可選的提醒時間，寫入「行事曆」。

📚 新增單詞

填中文、族語、例句與可選的 HTTPS 音檔網址，寫入「單詞表」。

💬 新增每日一句

選日期、填句子與翻譯；同一天再次提交會更新當天內容。

🔔 新增通知

填發送時間與內容，勾選「確認發送給已訂閱學生」後排入「通知」；學生機器人的定時程式負責送出。

這一版不是自由聊天的生成式 AI。

它只辨識固定指令並開表單，不會自動生成教材，也不需要付費 AI API。表單權限由 Google 帳號控制；公開的 LINE Webhook 不直接新增資料或群發訊息。

從頭安裝

先完成學生 LINE 入門版的 setup。確認同一份試算表已有「行事曆」「單詞表」「每日一句」「通知」等七張分頁，再做下列步驟。

先核對兩個時區。

在原 Google 試算表點「檔案 → 設定」，確認時區是「(GMT+08:00) 台北」；老師 Apps Script 的「專案設定」也要選 Asia/Taipei，再執行 setupTeacher。

  1. 準備老師專用 LINE 官方帳號

    另建一個只給老師自己加入好友的 LINE 官方帳號與 Messaging API channel。學生原本的官方帳號照常使用；老師這個助理需要自己的 Channel access token。先不要把 token 貼到網頁或程式裡。

    完成後會看到：你有學生用、老師用兩個不同的官方帳號；資料仍使用原本同一份 Google 試算表。

  2. 建立新的 Apps Script 專案，貼完整 Code.gs

    在瀏覽器開啟 Apps Script 新專案，把預設 Code.gs 全選刪除，貼上本頁下載或複製的完整程式。這是老師助理的新專案，不要覆蓋學生機器人的程式。

    完成後會看到：新專案內只有一份老師助理的 Code.gs；學生原有專案還在。

  3. 只設定一次原試算表網址和老師帳號

    開啟原本的 Google 試算表，從瀏覽器網址列複製完整網址。回到老師助理 Code.gs 最上方，只修改 TEACHER_SHEET_INPUT（貼原試算表完整網址或 ID）與 TEACHER_EMAIL_INPUT（填你實際登入的 Google 帳號電子郵件），按 Ctrl+S 儲存。不要另建一份學生資料表。

    完成後會看到：程式指向學生機器人正在使用的同一份試算表，並知道哪個 Google 帳號能填教師表單。

  4. 執行 setupTeacher 建立四份表單

    先在 Apps Script 左側齒輪「專案設定」確認時區為 Asia/Taipei。接著在上方「函式」選單選 setupTeacher，按「▶ 執行」，依畫面完成 Google 授權。程式會檢查原試算表欄位、建立四份尚未發布的 Google 表單，連接回原試算表，並安裝表單送出時的處理觸發器。再次執行不應重複建立表單或觸發器。

    完成後會看到：執行紀錄顯示四份表單的編輯連結；原試算表會多出表單的原始回覆分頁和老師處理紀錄分頁，原本七張教學分頁不會清空。

  5. 逐份確認「只有老師可以回覆」，再發布

    打開執行紀錄中的每一個表單編輯連結，點右上「分享」或「發布 → 管理」：一般存取權保持「受限制」，回覆者只加入你自己的 Google 帳號。確認「收集電子郵件地址」使用已驗證，沒有開「每人只能回覆一次」，也沒有開放回覆結果摘要。四份都確認後，才按「發布」。可用未獲授權的另一個 Google 帳號試開填寫連結，應顯示沒有權限。

    完成後會看到：老師登入自己的 Google 帳號能填；其他帳號即使拿到連結也無法填。若你無法確認這點，先不要啟用 LINE 入口。

  6. 執行 enableTeacherLinks

    回到 Apps Script，從函式選單選 enableTeacherLinks，按「▶ 執行」。它會檢查四份表單已發布、仍開放填寫，且連回原試算表，再讓 LINE 助理開始回傳表單連結。程式無法確認電子郵件是否採「已驗證」模式，所以不能省略上一個步驟的權限目視檢查與另一帳號測試。

    完成後會看到：執行紀錄顯示老師助理表單入口已啟用。

  7. 設定老師 LINE 權杖，執行 checkTeacherSetup

    Apps Script 左側點齒輪「專案設定」→「指令碼屬性」→「新增指令碼屬性」。名稱填 LINE_ACCESS_TOKEN，值貼老師專用 LINE channel 的 Channel access token，儲存。不要拿學生官方帳號的權杖，也不要把 token 寫進 Code.gs。接著執行 checkTeacherSetup 確認設定。

    完成後會看到：指令碼屬性清單有 LINE_ACCESS_TOKEN、檢查執行完成，程式碼仍不含權杖。

  8. 部署老師助理，連到老師 LINE channel

    在 Apps Script 右上點「部署」→「新增部署作業」→ 類型選「網頁應用程式」；執行身分選「我」，存取權選「所有人」，按「部署」並複製結尾是 /exec 的網址。到老師 channel 的 LINE Developers「Messaging API」貼進 Webhook URL，開啟「Use webhook」，再按 Verify。這個公開端點只會回覆表單連結，寫入由受限的 Google 表單處理。

    完成後應看到：老師官方帳號的 Webhook Verify 顯示成功；請以你自己的 LINE channel 實測。若未成功，先核對 /exec 網址、部署存取權和 Apps Script「執行項目」；學生官方帳號原本的 Webhook URL 不變。

  9. 自己傳訊息、填一筆測試資料

    用老師自己的 LINE 加入老師官方帳號，傳「說明」再傳「新增課程」。點回覆的表單連結，用被授權的 Google 帳號填一筆未來課程並送出。回原試算表，確認「行事曆」分頁增加一筆；再到學生 LINE 官方帳號傳「行事曆」確認看得到。單詞與每日一句也可用同樣方式試一次。

    完成後會看到：老師 LINE 有填寫入口、表單有回覆、原試算表有新列、學生 LINE 能查到。

老師在 LINE 傳什麼？

說明看四個填寫入口。
新增課程開啟課表表單。
新增單詞開啟單詞表單。
新增每日一句開啟當日句子表單。
新增通知開啟發送給訂閱學生的通知表單。

LINE 訊息只負責帶你到表單。填完後以原試算表實際新增或更新的資料為準；LINE 不會在表單送出後再發一則確認訊息。

表單送出後，去哪裡看？

填寫表單原試算表的正式資料分頁學生端看到什麼
新增課程行事曆學生傳「行事曆」看到最近的未來課程；有提醒時間時由學生端定時程式處理。
新增單詞單詞表學生傳「單詞表」或「查單詞 關鍵字」。
新增每日一句每日一句日期等於台灣今天時，學生傳「每日一句」可看到。
新增通知通知到發送時間後，學生端的 sendDueNotifications 觸發器向已訂閱帳號推播。
表單原始回覆也會在同一份試算表。

那些新增的「表單回應」分頁是備份；學生機器人讀的是表格中的「行事曆」「單詞表」「每日一句」「通知」。通知不會在老師按下送出表單的瞬間立即發送，仍以學生端定時觸發器為準。

要現在發給學生？另加一個 .gs 檔就好

老師在 LINE 送出「新增通知」表單後，資料會先進原試算表的「通知」分頁，按原排程時間送出。若要立刻發送，可以在原試算表加一個獨立的 ImmediateSend.gs，選取那筆通知後點「LINE 通知 → 立即發送選取的通知」，核對內容和待發送人數再確認。

原本兩份 Code.gs 都保持不動。

新增檔案要貼進學生版與試算表連動的 Apps Script 專案，因為那個專案持有學生 LINE 的權杖；不要貼到本頁的老師專用助理專案。點發送時會把通知的「發送時間」改成現在，每次最多嘗試 20 位；再次點擊時，程式會跳過「發送紀錄」中已有成功紀錄的對象。

權限與限制

  • 四份 Google 表單必須只開放老師帳號回覆；表單網址不是密碼，所以不能設成「知道連結的人都能回覆」。
  • 若其他人加入老師 LINE 官方帳號，也可能在一對一聊天取得表單連結；請勿把這個帳號公開給學生。這份 GAS Webhook 只回覆連結，不接收新增資料指令；真正的填寫限制是 Google 表單的受限帳號與已驗證 Email。
  • 四份表單的原始回覆也會存進同一份試算表，其中可能有老師的電子郵件；試算表本身請維持老師管理，不要開放學生瀏覽或編輯。
  • 「行事曆」是試算表課表，不會同步 Google Calendar。要改課程時間或取消課程，先到原試算表修改；這版表單只處理新增，當日句子例外可覆寫同一天資料。
  • 老師助理和學生機器人各用一個 Channel access token；兩個權杖都只存放在各自的 Apps Script「指令碼屬性」。修改過的 Code.gs 含你的試算表 ID 與 Google 帳號，請勿上傳到公開儲存庫。
  • 請先用測試帳號與假資料驗收。這份程式沒有生成式 AI 對話，也不會憑空產生族語內容；族語拼寫與翻譯仍由老師確認。

卡住時先看這裡

LINE 有回連結，但表單說無法存取？

確認目前登入的是被加入「回覆者」的老師 Google 帳號，並確認該表單已發布。若你同時登入多個 Google 帳號，可先切到正確帳號。

表單送出了，學生 LINE 沒看到新課程？

先看原試算表「行事曆」有沒有新列，時間是否在未來、啟用是否為「是」。若只在原始表單回應分頁找到資料，請查看老師 Apps Script 左側「執行項目」中表單觸發器是否報錯。

新增通知後沒有推播？

確認學生端專案已執行 installTrigger、目標學生傳過「訂閱」、通知時間已到且在有效範圍內；查看原試算表「發送紀錄」與學生端 Apps Script「執行項目」。

改了老師助理 Code.gs，LINE 還是舊回覆？

儲存後到「部署」→「管理部署作業」→「編輯」→ 選「新增版本」並部署。只儲存程式不會更新既有的 /exec 版本。
