五選一

挑一個你想拿來上課的主題

五個選項都做成三題／三關的小作品，難度與繳交標準相同。可換成自己教的學科；先把學習目標寫成一句話。

OPTION 01

單詞快問快答

給一個生活詞語，讓學生從三個選項挑正確意思或用法。可用族語、國語或外語；族語拼寫由老師核對。

OPTION 02

每日一句配對

用三句短句，讓學生選出對應的翻譯或使用情境；答錯時說明理由。

OPTION 03

故事讀後測

選一段有使用權的短文，設計三題理解題。重點是從文本找證據，而不是猜答案。

OPTION 04

課前暖身挑戰

針對下一堂課的重點設計三題預習題；最後用分數讓學生知道哪裡還要複習。

OPTION 05

生活情境判斷

給校園、家庭或社區情境，讓學生選較合適的做法或回應，再看解說。

教材內容由人確認。

AI 可以協助整理題型與修改網頁，但不能憑空替你確定族語、在地文化或專業事實。只用自己可使用、已核對的教材。

每個主題都要做到

四項共同完成標準

  1. 一頁可玩的網頁至少三題／三關，手機可操作；有答對、答錯回饋及最後分數。設計由 Vibe Coding 協助，但你要親自測試與修正。
  2. 一份試算表，GAS 真正讀寫題目從試算表讀取；送出後把時間、主題、分數、錯題寫進同一份試算表的「網頁作答」分頁。不要只在網頁假裝送出。
  3. 沿用現有 LINE Bot傳「今日挑戰」得到作品網址；傳「挑戰成果」讀取試算表裡的累計作答次數與平均分數。統計必須隨新作答變動，不可寫死。
  4. 完成一次真實連動測試從 LINE 點進網頁，至少測一次答對與答錯；送出後確認試算表多一筆，再從 LINE 查到更新後的統計。
LINE 入口→互動網頁→GAS→同一份試算表→LINE 查詢

不收真實學生姓名、班級或聯絡方式。這裡的分數只用來驗證連動，不是正式成績；公開網頁的測試送分可以被重複操作。

給初學者的路線

照這個順序做，比較容易找到問題

  1. 選主題，準備三題

    寫下一句學習目標，檢查題目、答案與答錯解說。先把三題放進同一份試算表；若沿用入門版，可使用現有「題庫」分頁。

  2. 先完成可獨立作答的網頁

    請 AI 幫你做手機版三題頁。先測選項、回饋和分數，不急著接 LINE。

  3. 接上 GAS 與試算表

    讓網頁從試算表取題、送出後新增一列到「網頁作答」。先在表格親眼看到一筆紀錄，再進下一步。

  4. 最後接原本的 LINE Bot

    新增兩個指令，更新原本的網頁應用程式部署版本。用 LINE 走完「拿網址 → 作答 → 查更新後統計」整圈。

提示，不是標準答案

卡住時先看這裡

同一個 GAS 專案，LINE 和網頁會不會打架？

原本的 doPost 接 LINE Webhook，請保留它。可調整原本的 doGet，讓開啟 /exec 時顯示 HTML 頁面；網頁可用 google.script.run 呼叫 GAS 函式讀題和記錄。專案裡不要再做第二個同名 doPost 或 doGet。

網頁看起來有分數，試算表卻沒有資料？

先確認你看到的是 GAS 真正新增的「網頁作答」列，而不是只有網頁上的成功文字；再看 Apps Script 左側「執行項目」的錯誤。題目分頁的欄名與 GAS 使用的欄位也要一致。

LINE 還是回舊內容？

修改 GAS 後只按儲存不夠。到「部署 → 管理部署作業」編輯原本的網頁應用程式，選新版本並部署；Webhook 繼續用原本的 /exec 網址。

不知道要怎麼請 AI 協助？

先給 AI 看現有程式結構和工作表欄名，請它列出「最少要改哪些地方」與每一步怎麼測；確認方向後再分段產生程式。不要讓它直接覆蓋已經能運作的 LINE 功能。

可以複製給 AI 的起始提示詞

繳交作品

讓老師看得出「三個工具真的接上了」

① 作品網址交可開啟的測驗網址到班級指定管道；不要把試算表開放所有人編輯。
② 試算表截圖題庫三題，以及「網頁作答」至少一筆測試紀錄。
③ LINE 測試截圖「今日挑戰」拿到網址，以及作答後「挑戰成果」數字更新。
④ 一次 AI 修正紀錄貼一段你給 AI 的提示詞，說明一個你發現並修好的問題。
交件前遮住這些資料：

LINE access token、Channel secret、老師通行碼、完整使用者 ID 與真實學生資料。只用自己或老師提供的測試帳號和測試內容。
