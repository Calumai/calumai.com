WHAT I MAKE / 01—03

不只是做遊戲。

我關心的是：怎麼把一個文化或教學主題，轉換成學生願意接近、老師可以使用的數位作品。

01

LANGUAGE + AI

族語 AI 教學

把 AI 當成備課與學習的協作工具，協助整理詞彙、設計練習、生成教學素材與規劃課堂流程；族語內容仍以人員確認與文化脈絡為核心。

02

MULTIMEDIA LEARNING

多媒體教學

結合文字、圖片、聲音、影片與互動頁面，把抽象的文化和語言內容做成容易進入、可以反覆操作的學習材料。

03

PLAYABLE CULTURE

互動遊戲創作

用遊戲規則承載故事、決策與練習，讓玩家不只是閱讀介紹，而是在選擇、失敗、重來與完成任務的過程中理解主題。

SELECTED WORKS / 001—005

目前的遊戲

每個作品都包含主題、玩法與體驗重點。點擊作品卡片，可以開啟可試玩的版本。

01
CASE / FOREST

LEGAL REASONING GAME

山林見證

原住民族法律推理遊戲。玩家進入一場與山林、權利與證據有關的案件，練習分辨證詞、推論與可以站得住腳的主張。

玩法
選擇律師或法官身份，閱讀案件資訊、聽取證詞，找出矛盾與推論缺口，再提出證據或判斷。
體驗重點
不是猜答案，而是練習用證據思考：哪些是事實、哪些是說法、哪些主張還需要被追問。
開啟作品
02
TRUKU / TRAIL

LANGUAGE ADVENTURE

峽谷行者 Canyon Walker

結合太魯閣族語學習的冒險卡牌遊戲，讓語言練習放進一段需要合作與選擇的山徑旅程。

玩法
翻開冒險與族語卡牌，回答詞彙或發音問題；答對可以修復山徑、取得加成，帶隊伍繼續前進。
體驗重點
把詞語記憶和「要不要繼續前進、怎麼照顧隊伍」的遊戲決策連在一起。
開啟作品
03
HUNT / PLAY

INTERACTIVE GAME

Hunter Game

以狩獵與探索為主題的互動遊戲作品，從觀察環境、尋找目標到完成任務，嘗試建立更有動作感的遊玩流程。

玩法
在遊戲場景中移動與觀察，尋找可互動的目標，完成狩獵或探索任務，依照結果繼續下一步。
體驗重點
透過探索、瞄準與回饋，讓玩家感受「看見線索—做出行動—得到結果」的互動節奏。
開啟作品
04
BUILD / ROOTS

CULTURE STRATEGY GAME

原地重生・返璞歸真

文化策略桌遊數位版。玩家從素材與工藝開始，慢慢建造家屋，讓一個聚落在事件與互動中成形。

玩法
選擇族群後蒐集素材，完成工藝、建造本族家屋，並處理公共事件與玩家之間的互動。
體驗重點
理解資源、工藝、家屋與聚落之間的關係；每次選擇都會影響完成建設的速度與策略。
開啟作品
05
WORD / QUEST

RETRO LANGUAGE DEMO

森林詞語冒險

森林詞語冒險：爆彈配對 Demo。以復古遊戲機的節奏，讓詞語配對成為可以反覆嘗試的學習體驗。

玩法
在倒數與壓力中翻找卡片，配對正確的詞語；完成配對、避開爆彈，累積分數並挑戰下一輪。
體驗重點
把詞語辨識變成短回合、可重玩的挑戰，讓玩家透過記憶、速度與再試一次慢慢熟悉內容。
開啟作品
